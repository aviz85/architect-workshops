## The Big Idea

**Skills are born from friction, not planning.**

The fundamental mistake people make with AI agents: they try to *plan and build* upfront.
The right approach: work normally, notice friction, convert friction to permanent asset (Skill).

### The Core Loop

```
Work → Friction → TSK (Tweak Skill) → Asset → Compound
```

This is NOT:
- Planning agent architecture upfront
- "Building" an automation system
- Sitting down to "learn AI"

This IS:
- Working on real tasks with Claude as partner
- Noticing repetition or friction ("I keep correcting this...")
- Creating a Skill from the solution
- Moving on

### Why This Works

1. **No wasted effort** - Only create skills for real problems
2. **Contextual learning** - Skills emerge from actual use cases
3. **Low activation energy** - No "learning curve" to climb
4. **Exponential compounding** - Each skill enables the next

## The Gap to Bridge

### Current Reality
- Aviz has intuitive mastery
- Only 10-20% of workshop participants "catch the wave"
- Those who do have "that look in their eyes" - transformative
- 80-90% need a clearer path

### Why People Fail
1. **Plan-first mentality** - "I'll sit down and build my agent system"
2. **Effort expectation** - "This should be hard work"
3. **Tool mentality** - Treating it as another app to learn
4. **Fear of terminal** - The "black screen" barrier

### What Needs to Happen
- Lower the activation threshold dramatically
- Shift from "learning" to "working with"
- Make the terminal feel like home (or find alternative)
- Provide scaffolding without removing agency

## The Method - Step by Step

### For Individuals

1. **Start a project** - just a folder
2. **Open Claude Code** - `code .` in terminal
3. **Treat it as a partner** - share context, documents, methods
4. **Work normally** - on your actual tasks
5. **Notice friction** - when Claude doesn't get it right
6. **TSK** - create/tweak a skill from the friction
7. **Repeat** - skills compound

### Key Micro-Behavior: TSK
When Claude does something wrong or suboptimal:
- Don't just correct this instance
- Say "TSK" (Tweak Skill)
- Claude updates the skill for all future cases
- Problem solved permanently

### Example: The Wife's WhatsApp Message
> "הבוט ניסח את ההודעה בצורה לבבית מדי וזה קריפי. אז תיקנתי אותו: 'תנסח את ההודעה בצורה פשוטה ועניינית בלי רגשות'. ואז TSK - ומעכשיו הוא יודע איך שולחים הודעה לאשתי. סגור."

### Example: Monthly Summary
> "ישבתי עם קלוד על הנתונים, חצי שעה, שעה. עשינו את זה פעם אחת. הנקודה היא - שאחרי שעשינו את זה פעם אחת והצלחנו בסוף להגיע לדו״ח טוב - זהו. מעכשיו קלוד מתבונן בכל המסלולים שעשינו... והכל הוא שם בתוך סקיל."

## For Businesses

### The Scaffolding Model

Don't sell:
- Ready-made agents (fish)
- Agent-building courses (fishing rod)

Sell:
- **The aquarium** - organizational structure (folders, base skills, CLAUDE.md)
- **Feeding instructions** - just TSK

### The Promise to Business Clients
"אני בונה לכם את התשתית. מלמד אתכם פעולה אחת: TSK. מהיום והלאה - כל פעם שהסוכן טועה, במקום לכעוס - אתם מתקנים אותו לתמיד."

### Why This Beats Traditional Automation
| Automation (Zapier/Make) | The Method |
|--------------------------|------------|
| Rigid, breaks when things change | Adapts through TSK |
| Built by specialist | Refined by anyone |
| Black box | Readable documents |
| One-time setup | Continuous improvement |

## Workshop/Course Ideas

### Option A: Mini-Kit (Quickest to Market)
Not a course, a starter package:
1. Pre-configured `.claude/` folder structure
2. 3 essential starter skills (universal)
3. One-page "protocol" document
4. 10-minute video: "Your first TSK"

**Goal:** Get them to taste the gold in 10 minutes

### Option B: Workshop - "The Method" (2-3 hours)
- Part 1: The paradigm shift (terminal as home)
- Part 2: Live work session (not "demo" - actual work)
- Part 3: First TSK moment for each participant
- Part 4: Building your first skill together

**Goal:** Everyone leaves having done one real TSK

### Option C: Course - "From Zero to Partner" (Multi-week)
Week 1: Setup + first project + first friction
Week 2: TSK practice + 3 personal skills
Week 3: Project architecture + linking skills
Week 4: Sub-agents + automation layer

**Goal:** Sustainable practice, not just knowledge

### Option D: B2B Package - "Organizational Scaffolding"
- Initial setup: folder structure, CLAUDE.md, base skills
- Training: One session teaching TSK to key personnel
- Monthly check-in: Review skill library, suggest improvements

**Goal:** Self-sustaining agent culture in the org

## Concerns & Risks

### The World is Moving Fast
> "העולם יתפרץ לשם מהר מדי בצורה לא מודעת ולא מסודרת ואז המחשבה שלי להעניק פה תהליך מודע וסדיר - די תטבע בתוך האוקיינוס של התנועה בשטח."

**Counter:** Position as "the responsible adult" - the balanced approach that survives when hype dies.

### Terminal Barrier
Many people fear the black screen.

**Options:**
1. Embrace it: "To touch gold, you need to get your hands dirty"
2. Find bridge: GUI wrappers that maintain the philosophy
3. Segment: Some offerings for terminal-comfortable, some not

### FOMO vs Substance
Too much excitement can create negative reactions.

**Approach:** Cool down the language, show don't tell, let results speak.
