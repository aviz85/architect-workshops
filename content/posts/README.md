# Posts

All published / draft Facebook (and future platform) posts live here as Obsidian-compatible notes.

## Naming

`YYYY-MM-DD-short-english-slug.md`

## Structure

Each post file has:
- Frontmatter — date, platform, status, tags
- Title (H1)
- Raw idea callout — the original input verbatim, for reference
- `## Post` section — the final body that goes to Facebook
- `## Meta` — published URL, reach, etc. (filled after publishing)

## Wikilinks

Use `[[concept-name]]` to link to:
- Other posts in this folder
- Concepts in `../` (e.g. `[[exponential-efficiency]]`)
- Workshops (`[[workshops/2026-04-30-loop]]`)
- Future-concepts (`[[future-concepts/concept-name]]`)

If a concept doesn't exist yet, don't fabricate the link — either omit it or add a TODO at the end of the file.
