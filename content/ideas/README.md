# Ideas & Drafts

Raw ideas, draft concepts, and unformed thoughts — captured from conversations, voice messages, random inspiration.

## Naming

`YYYY-MM-DD-short-slug.md`

## Structure

Each idea file has:
- Frontmatter — date, source, status (raw/developing/ready), tags
- Title (H1)
- `## Raw` — the original input/quote/transcript verbatim
- `## Idea` — distilled concept (filled when developing)
- `## Next` — what to do with it (post? workshop? concept?)

## Status Flow

`raw` → `developing` → `ready` → moved to posts/ or future-concepts/

## Sources

Ideas come from:
- WhatsApp conversations (voice + text)
- Random thoughts (captured via /memo or manually)
- Workshop feedback
- Social media comments
- Conversations with collaborators
