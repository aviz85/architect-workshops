## 5. KNOWLEDGE MANAGEMENT (Second Brain)

### COG: Self-Evolving Second Brain
- **Features**: Self-learning, auto-classification, consolidates scattered insights, self-healing (updates cross-references automatically)
- **Six Specialized Skills**: onboarding, braindump, daily-brief, url-dump, weekly-checkin, knowledge-consolidation
- **Verification-First**: All info requires sources with dates, news verified across multiple sources, confidence levels
- **Setup**: 2 minutes to clone + onboard, plain markdown files, works with Obsidian Tasks

Source: [COG Second Brain](https://github.com/huytieu/COG-second-brain)

- **Local-First Approach**: Plain-text markdown files Claude Code can read/write/manipulate directly
- **Better than Notion**: Notion requires MCP server, Obsidian allows direct file system work
- **Integration**: Obsidian Tasks with emoji-formatted dates for queryable dashboards

Sources:
- [AI-Powered Second Brain](https://sonnyhuynhb.medium.com/i-built-an-ai-powered-second-brain-with-obsidian-claude-code-heres-how-b70e28100099)

- **Replaces**: Evernote, Notion, Asana, and Otter.ai

- **Portable**: No database lock-in, multi-device syncing
