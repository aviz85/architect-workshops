# לגור בתוך סוכן — תוכנית אקסלרטור בנימין

> 3 מפגשים × 3 שעות | סטרטאפיסטים שרוצים לרוץ עם סוכנים

## Logistics

| Field | Value |
|-------|-------|
| **Format** | 3 sessions × 3 hours |
| **Total** | 9 hours |
| **Target audience** | Startup founders (mostly non-technical) |
| **Goal** | Work with AI agents across all startup processes |
| **Framework** | 7-Layer Model + Responsibility Loop |
| **Special track** | Marketing content automation (images, posts, videos, landing pages) |

## Target Audience Profile

- Startup founders in an accelerator program
- Most are NOT programmers — business/product people
- Need practical tools, not theory
- Building startups — time-poor, need ROI fast
- Each has a real product/service they're working on → exercises use THEIR startup

## Core Frameworks

### The 7-Layer Model

```
L6 — סקייל              multiply the process
L5 — תקשורת מרחוק       agent works while you're away
L4 — סוכנים ורוטינות     sub-agents + scheduled tasks
L3 — סקילים             training the agent on your knowledge + tools
L2 — אינטגרציות וכלים    connecting to real systems
L1 — פרויקט כבסיס ידע    project as knowledge base (built around YOUR startup)
L0 — קלוד קוד           foundation on the machine
```

### The Responsibility Loop

```
Action → Observe → Judge → Improve
```

At each step: does the agent have the ability to do this? If not — that's what you build next.

## Syllabus

### Session 1 — הבסיס: מהתקנה למוח שני (3 שעות)

**Layers 0 + 1 + 2**

**מטרה:** כל משתתף יוצא עם סוכן שמכיר את הסטרטאפ שלו ומחובר לעולם האמיתי.

#### Block A — הצתה (20 דק')
- מה זה "לגור בתוך סוכן" — לא כלי, סביבה
- "ממש כמו לנהל עובד" — המטאפורה המרכזית
- מעגל האחריות: פעולה → צפייה → שיפוט → שיפור
- הדגמה: אביץ מראה את המערכת שלו — 30 שניות, לא יותר

#### Block B — Layer 0: התקנה והגדרה (30 דק')
- התקנת Claude Code (מי שלא מוכן — עוזרים 1-on-1)
- VS Code Extension + RTL fix (yechielby.claude-code-rtl)
- הגדרות בסיסיות, הרשאות
- Mental model: מה הסוכן רואה, מה לא

#### Block C — Layer 1: הסטרטאפ שלך כפרויקט (60 דק') ⭐
- כל משתתף בונה תיקיית פרויקט לסטרטאפ שלו
- CLAUDE.md — מי אתה, מה החברה, מה המטרה, מה הסטנדרטים
- Knowledge base — מסמכים, מתחרים, קהל יעד, pricing
- The long-term goal: הסוכן מנהל כיוון, לא רק משימות
- **תרגול:** כל אחד כותב CLAUDE.md לסטרטאפ שלו, מוסיף 3 מסמכי ידע, ובודק שהסוכן "מכיר" אותו

#### Block D — Layer 2: חיבור לעולם (40 דק')
- אינטגרציות רלוונטיות לסטרטאפ: email, WhatsApp, calendar, browser
- Live demo: חיבור אינטגרציה אחת
- **תרגול:** כל אחד מחבר לפחות אינטגרציה אחת לפרויקט

#### Block E — סיכום + שיעורי בית (30 דק')
- Review: הסוכן מכיר אותך? מחובר לכלי אחד? מעגל האחריות עובד?
- **שיעורי בית:** השבוע — דברו עם הסוכן כל יום. תנו לו משימה אמיתית. צפו, שפטו, שפרו.

**משתתף יוצא עם:** פרויקט + CLAUDE.md + ידע + אינטגרציה ראשונה

### Session 2 — סקילים + אוטומציית שיווק (3 שעות)

**Layers 3 + Marketing Automation Track**

**מטרה:** כל משתתף יוצא עם סקילים עובדים ויכולת לייצר חומר שיווקי אוטומטית.

#### Block A — Review שיעורי בית (15 דק')
- מה עבד? מה לא? איפה הלופ נשבר?
- 2-3 משתתפים משתפים חוויה

#### Block B — Layer 3: סקילים (45 דק')
- מה זה סקיל: מפעולה חוזרת ליכולת קבועה
- The compound effect: סקיל 1 מאפשר סקיל 2
- **תרגול:** כל אחד מזהה פעולה חוזרת בסטרטאפ → בונה סקיל

#### Block C — Marketing Track: תמונות ופרסומים (45 דק') ⭐
- AI image generation: מפרומפט לפוסטר מקצועי
- כתיבת קופי שיווקי: פוסטים, הודעות, מודעות
- שילוב ידע הסטרטאפ: הסוכן כותב בסגנון שלך, עם ה-messaging שלך
- **תרגול:** כל אחד מייצר פוסטר + פוסט שיווקי לסטרטאפ שלו

#### Block D — Marketing Track: סרטונים (30 דק')
- AI video generation: מרעיון לסרטון שיווקי
- TTS (text-to-speech): נרציה בקול
- שילוב: תמונה → אנימציה → קול → סרטון
- **תרגול:** כל אחד מתחיל סרטון קצר (30 שניות) לסטרטאפ

#### Block E — Marketing Track: דפי נחיתה (30 דק')
- מפרומפט לדף נחיתה עובד
- Claude Code בונה Next.js / HTML מאפס
- Deploy to Vercel — באוויר תוך דקות
- **תרגול:** כל אחד מתחיל דף נחיתה (ממשיכים בשיעורי בית)

#### Block F — סיכום + שיעורי בית (15 דק')
- **שיעורי בית:** השלימו את דף הנחיתה. צרו 3 פוסטים שיווקיים. הריצו את מעגל האחריות על כל אחד.

**משתתף יוצא עם:** סקיל עובד + פוסטר + פוסט שיווקי + סרטון בתהליך + דף נחיתה בתהליך

---

### Session 3 — אוטונומיה וסקייל (3 שעות)

**Layers 4 + 5 + 6**

**מטרה:** המערכת רצה לבד. המשתתף חושב על הכפלה.

#### Block A — Review + Showcase (30 דק')
- משתתפים מציגים דפי נחיתה, סרטונים, חומר שיווקי שבנו
- מה עבד, מה לא, איפה הלופ עזר

#### Block B — Layer 4: סוכנים ורוטינות (45 דק')
- Sub-agents: סוכנים שמפעילים סוכנים
- Cron / scheduled tasks: משימות שרצות לפי לוח זמנים
- **תרגול:** כל אחד מגדיר רוטינה יומית/שבועית לסטרטאפ
  - דוגמאות: סריקת מתחרים שבועית, דו"ח שיווק יומי, פולואפ לקוחות אוטומטי

#### Block C — Layer 5: תקשורת מרחוק (30 דק')
- Background agents: הסוכן עובד כשאתה לא שם
- Remote triggers: אירועים שמפעילים את הסוכן
- **תרגול:** הגדרת background agent או trigger אחד

#### Block D — Layer 6: סקייל (30 דק')
- בניתם מערכת שעובדת. עכשיו מה?
- להכשיר צוות, לארוז כשירות, לשכפל לעסקים, לבנות מוצר
- **תרגול:** כל אחד כותב "Layer 6 plan" — מה ה-scale שלו?

#### Block E — Marketing Automation: הכל ביחד (30 דק')
- שרשרת שלמה: trigger → תוכן → עיצוב → פרסום
- Live demo: מאפס לפוסט מפורסם בדקות
- איך הסוכן מייצר תוכן שוטף בלי שתשבו על זה

#### Block F — סגירה (15 דק')
- Review: איפה הייתם לפני 3 מפגשים? איפה אתם עכשיו?
- מעגל האחריות כהרגל יומי
- The daily habit: בוקר, ערב, הקצב של לגור בפנים
- מה הלאה: איך ממשיכים לבד

**משתתף יוצא עם:** מערכת L0-L5 עובדת + תוכנית L6 + שרשרת שיווק אוטומטית

## Key Principles

- **100% hands-on** — כל בלוק: הדגמה → תרגול → עזרה 1-on-1
- **הסטרטאפ שלך** — כל תרגיל בנוי סביב העסק האמיתי של המשתתף
- **מעגל האחריות** — חוזר בכל מפגש: פעולה → צפייה → שיפוט → שיפור
- **שיעורי בית** — בין מפגשים המשתתפים מפעילים את המערכת ביומיום
- **לא צריך לדעת לתכנת** — Claude Code עובד בשפה טבעית, המשתתפים מנהלים, לא כותבים קוד

- [ ] 3+ marketing posts (social media ready)
- [ ] Short video (30-60 sec promo)

- [ ] Automated content pipeline (trigger → generate → publish)
