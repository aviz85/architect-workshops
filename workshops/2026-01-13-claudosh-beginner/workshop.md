### Claude Code for Complete Beginners

A gentle, accessible introduction to Claude Code. No technical background required! We start with the friendly Desktop App, explore easy real-world use cases, and then peek at the Terminal to see how powerful it can become.

## Overview

סדנה למי שרוצה לעבוד פחות ולהרוויח יותר - בלי להיות טכנולוגי.

**ההבטחה:** תקבלו סוכן AI שמכיר את העסק שלכם לפרטי פרטים - לא סתם AI גנרי שמתחיל מאפס כל פעם.

**מה מקבלים:**
- ערכת כלים מוכנה (מייל, וואטסאפ, תמונות, PDF) + מדריכי חיבור צעד-אחר-צעד

- סוכן שעובד בשבילכם מהיום הראשון

**הקונספט:** לא צריך להבין באוטומציה. לא צריך לבנות פלואוגרמים מסובכים. פשוט מדברים עם הסוכן והוא עושה - כי הוא מכיר אתכם.

הסדנה מתאימה למי שמעולם לא כתב שורת קוד!

### Part 1: הבנת העקרון - מה זה סוכן בכלל? (15 min)
**Goal:** להבין את הבסיס ולדעת לאן הולכים

**תיאום ציפיות (3 דק'):**
> "הנה מה שנעשה היום:
> 1. קודם נבין מה זה סוכן AI - בגדול, פשוט
> 2. אז תראו משהו שאתם יכולים לעשות מחר בבוקר!
> 3. אז אקח אתכם למסע על החללית שלי - להראות מה אפשרי
> 4. ובסוף - תקבלו מתנות שיתנו לכם גשרים לצמוח!
>
> **שאלות? נשמור לסוף - יש חלק ייעודי לשאלות!**"

**מה זה סוכן? (12 דק'):**
- מה זה "סוכן" בעולם ה-AI? (לא צ'אטבוט רגיל!)
- **הבעיה המרכזית:** צ'אט רגיל לא זוכר, לא פועל, מתחיל מאפס כל פעם

**🩺 משל הדוקטור הגאון:**
> דמיינו דוקטור גאון - הכי חכם בעולם.
> אבל כל בוקר הוא מתעורר ושוכח הכל:
> - מי המטופלים שלו?
> - מה הטיפולים שנתן אתמול?
> - מה ההיסטוריה הרפואית?
> - מה התוכניות לשבוע הבא?
>
> **האם הייתם רוצים שהוא יטפל בכם?**

**המסר:** אינטליגנציה לבד זה לא מספיק!
- ChatGPT הוא הדוקטור הגאון הזה
- חכם מאוד, אבל **שוכח הכל כל שיחה**
- זו הבעיה המרכזית של כל ה-AI עד היום

**🎯 המחשה קריטית - הפרומפט שאף סוכן לא יכול לבצע:**
> "שלח לחיים את הצעת המחיר שהוצאנו אתמול,
> שלח לו תזכורת עוד 10 דקות בוואטסאפ,
> תכין את החוזה לקראת שליחה ללקוח אחר,
> ותשלח לי את הטיוטה בוואטסאפ לאישור."

**למה שום סוכן קיים לא יכול לעשות את זה?**
- לא יודע מי זה "חיים" ומה המספר שלו
- לא יודע איפה הצעת המחיר מאתמול
- לא יודע מי "הלקוח האחר"
- לא יודע איך לשלוח וואטסאפ
- לא יודע מה הסגנון שלך לחוזים

**למה Claude Code כן יכול? המילה הקסומה: Context!**

עד היום האתגר הגדול היה **ניהול הקונטקסט**. Claude Code פותר את זה דרך שילוב ייחודי:

**1. סוכן קוד + ניהול קבצים = זיכרון לטווח ארוך**
- הקבצים על המחשב שלך הם הזיכרון שלו
- לא מתחיל מאפס - יודע מה עשית אתמול, מי הלקוחות, מה הסגנון

**2. מודל שאומן לעבוד עם זיכרון לטווח ארוך**
- זה קריטי! המודל יודע לנהל את ה-state שלו
- מאומן להתבונן בסביבה (קבצים, תיקיות) לפני שפועל
- לא "יורה מהמותן" - קודם מבין, אז עושה

**3. יכולת לרוץ ברצף - בלי להתעייף**
- 🏆 **אנקדוטה:** Claude 4.5 Opus שבר שיא בריצה רצופה!
- משימות מורכבות שלוקחות שעות - הסוכן פשוט ממשיך

**התוצאה: "האפליקציה הסוכנית"**
- יושב על פרויקטים במחשב שלך
- חמוש בסקילים (הנחיות ארוזות)
- חוקים והגדרות פר-פרויקט (CLAUDE.md)
- מחובר לכלים (מייל, וואטסאפ, תמונות...)
- **חיבור חזק לשטח - מכיר את העסק שלך לפרטי פרטים!**

- 🎁 הכרזה על המתנות (ערכת כלים + הגרלת 3 passes)
- ✅ Checkpoint: "האם העיקרון ברור? מה ההבדל בין צ'אט רגיל לסוכן?"

### Part 2: התחלה נגישה - עושים ביחד! (25 min)
**Goal:** לעשות משהו בפועל - לא רק לצפות!

> **חשוב:** בחלק הזה המשתתפים עושים ביחד, לא רק צופים!

**הממשק הפשוט (5 דק'):**
- Claude Desktop App - כמו וואטסאפ עם AI
- מראים את הממשק, מסבירים מה רואים

**🔧 פרקטיקה 1: התקנה ביחד (10 דק'):**
- התקנת Claude Code - צעד אחרי צעד
- **כולם עושים ביחד!**
- הגדרות ראשוניות פשוטות
- ✅ Checkpoint: "מי הצליח להתקין? תרימו יד!"

**🔧 פרקטיקה 2: הטריק הכי שימושי - קיצור `cc`! (5 דק'):**

**מה נעשה:** נגדיר קיצור כך שבמקום לכתוב את כל הפקודה, פשוט נכתוב `cc`

| מערכת | איך מגדירים |
|-------|------------|
| **Mac/Linux** | הוסיפו ל-`~/.zshrc`: `alias cc="claude --dangerously-skip-permissions"` |
| **Windows** | פתחו PowerShell, כתבו `notepad $PROFILE`, הוסיפו: `function cc { claude --dangerously-skip-permissions }` |

- **למה הדגל הזה?** הסוכן רץ בלי לשאול אישור על כל פעולה (מצב "אני סומך עליך")
- סוגרים ופותחים מחדש את הטרמינל
- מנסים: `cc`
- ✅ Checkpoint: "מי הצליח להריץ `cc`?"

> **הערה למציג:** להסביר שה-"dangerously" זה שם מפחיד אבל בפועל זה אומר
> שהסוכן עובד ברצף בלי לעצור - כמו עובד שסומכים עליו!

**🔧 פרקטיקה 3: הורדת Skill מהספרייה (5 דק'):**
- פותחים את ספריית הסקילים: `github.com/aviz85/claude-skills-library`
- **הסקיל שנתקין:** `presentation-architect`
  - קובץ אחד בלבד - בלי תלויות!
  - בלי API keys
  - "וואו" מיידי

**התקנה לפי מערכת הפעלה:**

| מערכת | פקודה |
|-------|-------|
| **Mac/Linux** | `cp -r claude-skills-library/skills/presentation-architect ~/.claude/skills/` |
| **Windows (PowerShell)** | `Copy-Item -Recurse claude-skills-library\skills\presentation-architect $env:USERPROFILE\.claude\skills\` |

> **חשוב:** Windows users - להשתמש ב-PowerShell, לא Command Prompt!

- **מנסים:** "תכין לי מצגת על איך להתחיל עם AI"
- ✅ Checkpoint: "מי הצליח להריץ את הסקיל?"

💡 **המסר:** "עכשיו יש לכם סוכן עובד עם סקיל מותקן. זה לא תיאוריה - זה אמיתי!"

## 🔧 Technical Setup - הגדרות למציג

### הגדרת קליק ימני → פתיחת Claude (Mac)

**אפשרות 1: Automator Quick Action (מומלץ)**

1. פתח Automator → New → Quick Action
2. הגדר: "Workflow receives current **folders** in **Finder**"
3. הוסף: "Run Shell Script"
4. הדבק:
   ```bash
   for f in "$@"; do
       open -a Terminal "$f"
       sleep 0.5
       osascript -e 'tell application "Terminal" to do script "claude --dangerously-skip-permissions" in front window'
   done
   ```
5. שמור בשם: "Open Claude Here"
6. עכשיו יופיע בקליק ימני על תיקייה!

**אפשרות 2: iTerm2 (אם משתמשים)**

1. iTerm2 → Preferences → Profiles → General
2. הגדר "Send text at start": `claude --dangerously-skip-permissions`

**אפשרות 3: Alias/קיצור פשוט (למשתתפים)**

**Mac/Linux** - להוסיף ל-`~/.zshrc` או `~/.bashrc`:
```bash
alias cc="claude --dangerously-skip-permissions"
```

**Windows (PowerShell)** - להוסיף ל-PowerShell Profile:
```powershell
# פתיחת הקובץ (יצירה אם לא קיים):
notepad $PROFILE

# להוסיף את השורה:
function cc { claude --dangerously-skip-permissions }
```

> **טיפ:** אחרי שמירה, לסגור ולפתוח מחדש את הטרמינל/PowerShell

אז פשוט כותבים `cc` במקום הפקודה המלאה!

## Beginner Workshop Guidelines

### Core Principles for Absolute Beginners

1. **"Tell them what you'll tell them"** - פתיחה עם מפת דרכים ברורה
2. **One concept at a time** - לא לקפוץ בין נושאים
3. **Show, then do** - קודם הדגמה, אח"כ תרגול
4. **Celebrate small wins** - לחגוג כל הצלחה קטנה
5. **No jargon** - להימנע ממונחים טכניים או להסביר כל מונח

### Workshop Flow Structure

```
📍 WHERE WE ARE NOW (בתחילת כל חלק)
   ↓
📋 WHAT WE'LL DO (מה נלמד בחלק הזה)
   ↓
👀 WATCH ME (הדגמה חיה)
   ↓
🎯 KEY TAKEAWAY (נקודה אחת לזכור)
   ↓
✅ CHECKPOINT (וידוא שכולם עוקבים)
```

### Opening Script (First 5 minutes)

1. **ברוכים הבאים** - חיוך, אנרגיה חיובית
2. **מי אני** - הצגה קצרה
3. **מה נעשה היום** - 3-4 נקודות פשוטות
4. **הבטחה** - "בסוף הסדנה תדעו לעשות X"
5. **הרגעה** - "אין צורך בידע קודם, נלך צעד צעד"
6. **מתנה!** - הכרזה על ההגרלה (3 passes)

### Checkpoint Questions (לשאול במהלך הסדנה)

- "האם כולם רואים את המסך?"
- "מי הצליח להגיע לשלב הזה? תרימו יד"
- "יש שאלות עד לפה?"
- "מה הדבר החשוב שלמדנו עכשיו?"

### Visual Aids Needed

- [ ] מפת דרכים ויזואלית (איפה אנחנו בסדנה)
- [ ] צ'קליסט התקנה על המסך
- [ ] דוגמאות פשוטות מוכנות מראש
- [ ] "למדנו עד עכשיו" slide בין חלקים
