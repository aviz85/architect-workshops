### Claude Code for Complete Beginners

A gentle, accessible introduction to Claude Code. No technical background required! We start with the friendly Desktop App, explore easy real-world use cases, and then peek at the Terminal to see how powerful it can become.

**Getting Started**
- Installing Claude Code Desktop App
- First conversation with your AI agent
- Understanding what makes Claude Code different

- Writing and editing documents
- Organizing files and folders
- Simple automation tasks anyone can do
- Real examples you can try today

**A Glimpse of Power**
- Introduction to the Terminal interface
- Why the Terminal unlocks more possibilities
- Roadmap: where to go from here

## Agenda (90 min)

### Part 1: מה זה סוכן AI ולמה Claude Code? (15 min)
**Goal:** להבין את הרעיון ולהתלהב

- 📍 מפת דרכים - מה נעשה היום
- מה זה "סוכן" בעולם ה-AI? (לא צ'אטבוט רגיל!)

- הרמה החדשה של התייעלות - מה זה אומר בפועל

### Part 2: תראו מה עשיתי עם זה (15 min)
**Goal:** השראה - "וואו, אפשר לעשות את זה?!"

- הדגמות של פרויקטים שבניתי עם Claude Code
- דוגמאות מהחיים האמיתיים
- מה שהיה לוקח שעות - נעשה בדקות
- ✅ Checkpoint: "מה הכי הפתיע אתכם?"

### Part 3: התקנה והתחלה (20 min)
**Goal:** כולם מוכנים לעבוד

- התקנת Claude Code Desktop App (הדגמה חיה)
- הגדרות ראשוניות
- הממשק - מה רואים ואיפה לוחצים
- 💡 טיפ: מתחילים מהדסקטופ, אבל העוצמה האמיתית בטרמינל
- ✅ Checkpoint: "מי הצליח להתקין?"

### Part 4: בונים משהו יחד! (25 min)
**Goal:** התנסות מעשית - מהקטן לגדול

- נתחיל ממשהו קטן ופשוט
- נרחיב את זה צעד אחרי צעד
- 🔄 **הפוגה:** מבנה תיקיות - למה זה חשוב?
- נמשיך לבנות ולהרחיב
- 🔄 **הפוגה:** איך לבקש מהסוכן בצורה טובה

### Part 5: Skills - הכוח האמיתי (10 min)

- מה זה Skill ולמה זה משנה הכל

### Part 6: מתנות וסיום (5 min)

## Beginner Workshop Guidelines

### Core Principles for Absolute Beginners

1. **"Tell them what you'll tell them"** - פתיחה עם מפת דרכים ברורה
2. **One concept at a time** - לא לקפוץ בין נושאים
3. **Show, then do** - קודם הדגמה, אח"כ תרגול
4. **Celebrate small wins** - לחגוג כל הצלחה קטנה
5. **No jargon** - להימנע ממונחים טכניים או להסביר כל מונח

### Workshop Flow Structure

```
📍 WHERE WE ARE NOW (בתחילת כל חלק)
   ↓
📋 WHAT WE'LL DO (מה נלמד בחלק הזה)
   ↓
👀 WATCH ME (הדגמה חיה)
   ↓
🎯 KEY TAKEAWAY (נקודה אחת לזכור)
   ↓
✅ CHECKPOINT (וידוא שכולם עוקבים)
```

### Opening Script (First 5 minutes)

1. **ברוכים הבאים** - חיוך, אנרגיה חיובית
2. **מי אני** - הצגה קצרה
3. **מה נעשה היום** - 3-4 נקודות פשוטות
4. **הבטחה** - "בסוף הסדנה תדעו לעשות X"
5. **הרגעה** - "אין צורך בידע קודם, נלך צעד צעד"
6. **מתנה!** - הכרזה על ההגרלה (3 passes)

### Checkpoint Questions (לשאול במהלך הסדנה)

- "האם כולם רואים את המסך?"
- "מי הצליח להגיע לשלב הזה? תרימו יד"
- "יש שאלות עד לפה?"
- "מה הדבר החשוב שלמדנו עכשיו?"
