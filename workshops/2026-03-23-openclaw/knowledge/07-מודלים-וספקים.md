## בחירת מודל - ראשי + fallbacks

OpenClaw עובד עם **מודל ראשי** + **רשימת fallbacks**:

```json
{
  agents: {
    defaults: {
      model: {
        primary: "anthropic/claude-opus-4-6",
        fallbacks: [
          "openai/gpt-4o",
          "google/gemini-2-pro",
          "ollama/llama3"
        ]
      }
    }
  }
}
```

**הלוגיקה:** נסה ראשי → נכשל? → fallback 1 → נכשל? → fallback 2...

## Model Failover - מה קורה כשמודל נכשל?

OpenClaw מנהל **failover דו-שלבי**:

### שלב 1: rotation של Auth Profile
יש לך כמה API keys? OpenClaw מנסה אותן לפי תור:
1. `auth.order[provider]` (הגדרה ידנית)
2. `auth.profiles` (פרופילים מוגדרים)
3. `auth-profiles.json` (profiles שמורים)

**Session Stickiness:** אחרי בחירת auth profile, OpenClaw "נדבק" אליו לאורך ה-session (לחמם cache).

### שלב 2: fallback למודל הבא
אם **כל** ה-profiles של הספק נכשלו → עבור למודל הבא ב-fallbacks.

### Cooldown - Exponential Backoff
```
ניסיון 1 נכשל → המתן 1 דקה
ניסיון 2 נכשל → המתן 5 דקות
ניסיון 3 נכשל → המתן 25 דקות
ניסיון 4 נכשל → המתן 1 שעה (מקסימום)
```

**בעיית חשבון (billing):** disabled ל-5 שעות → 10 שעות → 24 שעות מקסימום.

## OAuth - אוטנטיקציה מתקדמת

### מה זה OAuth ב-OpenClaw?

**OAuth** מאפשר להשתמש ב-**חשבון קיים** (למשל ChatGPT) בלי API key:

1. OpenClaw פותח דפדפן לאישור
2. אתה מאשר גישה
3. OpenClaw מקבל access token + refresh token
4. Token מחודש אוטומטית לפני פקיעה

### היכן נשמרים הtokens?
```
~/.openclaw/agents/<agentId>/agent/auth-profiles.json
```

### Token Sink
OpenClaw מאחד tokens מכל הלקוחות ל-"sink" אחד - מונע logout בגלל login ממקום אחר.

### Anthropic Setup Token
```bash
openclaw models auth setup-token --provider anthropic
```
מאפשר שימוש ב-Claude Pro/Max subscription בלי API key.

## Multiple Auth Profiles

ניתן להגדיר **כמה profiles** לאותו ספק:

```bash
openclaw agents add work    # סוכן לעבודה
openclaw agents add personal # סוכן אישי
```

**כל סוכן** עם auth profiles שלו - לא משותפים אוטומטית.

