# פרק 2: ארכיטקטורה - איך OpenClaw עובד מבפנים?

## המבנה הבסיסי

OpenClaw מורכב מ-4 רכיבים עיקריים שמדברים אחד עם השני:

```
[WhatsApp / Telegram / Discord]
            ↓
        [ GATEWAY ]  ← הלב של המערכת
            ↓
      [ AGENT RUNTIME ]  ← המוח - ה-AI
            ↓
    [הכלים: קבצים, גלישה, Cron]
```

---

## Gateway - השכבה החיצונית

ה-**Gateway** הוא ה"שומר הסף" של OpenClaw:
- מתחבר לכל ערוצי התקשורת (WhatsApp, Telegram, Discord...)
- **דייגים אחד בלבד** - Gateway אחד לכל ה-accounts
- מקשיב על `127.0.0.1:18789` (WebSocket)
- מנהל חיבורי Clients ו-Nodes

**הכלל הזהב:** Gateway אחד = WhatsApp session אחד. לא ניתן להפעיל שתי Gateways על אותו מחשב.

---

## WebSocket - שפת התקשורת הפנימית

כל החלקים של OpenClaw מדברים ביניהם דרך **WebSocket** עם JSON:

```
שאלה: { type: "req", id: "1", method: "agent", params: {...} }
תשובה: { type: "res", id: "1", ok: true, payload: {...} }
אירוע: { type: "event", event: "agent", payload: {...} }
```

**אבטחה:** ניתן להגדיר `OPENCLAW_GATEWAY_TOKEN` - ואז כל חיבור חייב לשלוח את ה-token.

---

## Clients - מי מחובר ל-Gateway

ל-Gateway יכולים להתחבר מספר סוגי לקוחות:

| סוג | דוגמה | מה הוא עושה |
|-----|-------|------------|
| **Web Admin** | Control UI בדפדפן | ניהול וצפייה |
| **CLI** | `openclaw` בטרמינל | פקודות ישירות |
| **macOS App** | אפליקציית שורת תפריטים | ממשק גרפי |
| **Node** | iOS / Android / headless | מכשיר שמרחיב יכולות |

---

## Nodes - מכשירים חכמים

**Node** הוא מכשיר שמתחבר ל-Gateway ומוסיף יכולות ייחודיות:

- **iOS Node:** מצלמה, מיקום GPS, הקלטת מסך, קול
- **Android Node:** מצלמה, קול, Canvas (תצוגה גרפית)
- **Headless Node:** שרת ללא מסך (לאוטומציה)

**פאירינג:** כל Node מצטרף אחרי אישור ידני - אי אפשר להתחבר בלי רשות.

---

## Canvas - ממשק גרפי חי

OpenClaw תומך ב-**Canvas** - עמוד HTML/CSS/JS שהסוכן יכול לערוך בזמן אמת:
- רץ תחת `/__openclaw__/canvas/`
- הסוכן כותב HTML → הדפדפן/מכשיר מציג
- מתאים לדאשבורדים, טפסים, ויזואליזציות

---

## גישה מרחוק - Tailscale / SSH

ה-Gateway מאזין רק על `127.0.0.1` (לוקאלי). לגישה מרחוק:

**מומלץ:** Tailscale VPN - מחבר את המחשבים שלך ל-רשת פרטית מאובטחת

**חלופה:** SSH Tunnel:
```bash
ssh -N -L 18789:127.0.0.1:18789 user@your-server
```

## סדר פעולות - מהודעה עד תשובה

1. **הודעה נכנסת** מ-WhatsApp → Gateway מקבל
2. **Routing** - לאיזה סוכן לשלוח?
3. **Session** - איזה שיחה? (חדשה / ממשיכה)
4. **Queue** - האם הסוכן עסוק? (מוסיפים לתור)
5. **Agent Run** - הסוכן עובד: AI + כלים
6. **Streaming** - תשובה נשלחת חזרה
7. **Persistence** - ה-session נשמר ב-JSONL

```
📱 WhatsApp → Gateway → Router → Session → Queue → 🤖 AI → כלים → 💬 תשובה
```
