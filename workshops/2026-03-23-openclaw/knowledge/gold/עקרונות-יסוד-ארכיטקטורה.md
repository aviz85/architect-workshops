## מה זה OpenClaw בעצם

OpenClaw הוא **gateway (שער)** בין מנוע חשיבה (LLM) לבין יכולות ברמת המערכת.
זה לא צ'אטבוט. זה לא כלי אוטומציה. זה **סוכן שעושה דברים**.

> "Unlike a standard chatbot that simply lives within a web UI and generates text, an AI agent can actually act."

### ההבדל הקריטי:
- **ChatGPT/Claude chat**: אתה שואל, הוא עונה, אתה מבצע
- **n8n/Zapier**: אוטומציה נוקשה, זורם קבוע מוגדר מראש
- **OpenClaw**: הסוכן מבין הוראות, מתכנן, מבצע, מדווח - בלי שתגדיר כל שלב

## 6 הרכיבים של OpenClaw

### 1. Gateway (הדלת הקדמית)
מתחבר ל-WhatsApp, Telegram, Slack, Discord, iMessage, ועוד 50+ פלטפורמות.
המשתמש מדבר מהאפליקציה שהוא כבר משתמש בה - אין ממשק חדש ללמוד.

### 2. LLM (המוח)
אגנוסטי למודל. אפשר להחליף בין Claude, GPT, Gemini, DeepSeek, Llama מקומי.
**מפתח**: השתמש במודל זול לניהול, במודל יקר לעבודה הכבדה.

### 3. Pi Agent (הידיים)
**הרכיב הפורץ דרך**. מאפשר ל-LLM:
- ליצור, לערוך, להריץ, ולמחוק קבצים
- להריץ פקודות shell
- לשלוט בדפדפן
- לקרוא ולכתוב APIs
**המודל כותב קוד אינטגרציה בעצמו** במקום שמפתח יגדיר כל חיבור.

### 4. Memory (האישיות)
אחסון מתמשך דרך קבצי markdown:
- `AGENTS.md` - תצורה ופרוטוקולים
- `SOUL.md` - אישיות והעדפות
- `MEMORY.md` - ידע לטווח ארוך
- `memory/YYYY-MM-DD.md` - יומן יומי

### 5. Cron & Heartbeat (הדופק)
- **Heartbeat**: בדיקות כל 30 דקות - אימייל, לוח שנה, משימות, מזג אוויר
- **Cron**: עבודה מתוזמנת חוזרת ונשנית ללא הפעלה מהמשתמש
הסוכן **יוזם** - לא רק מגיב.

### 6. Skills (המומחיות)
תבניות prompt שמאוחסנות כ-markdown. הסוכן מזהה ומפעיל skill רלוונטי אוטומטית.
"כתוב PRD" = הסוכן מושך את ה-skill המתאים מעצמו.

## הלולאה האגנטית (The Agentic Loop)

```
INPUT (הודעת צ'אט / טריגר)
    ↓
PERCEIVE (שלב עם זיכרון + הקשר)
    ↓
PLAN (LLM מייצר שרשרת חשיבה)
    ↓
ACT (מבצע skills: פקודות shell, API calls, דפדפן)
    ↓
OBSERVE (מלכד תוצאות, מעדכן זיכרון)
    ↓
COMMUNICATE (מדווח למשתמש, מפעיל המשך אם צריך)
    ↓
REPEAT (עוקב ברציפות אחר קלטים חדשים)
```

**ההבדל מ-RPA (Robotic Process Automation)**: הסוכן מסגל את הגישה שלו תוך כדי ביצוע - לא רק עוקב אחר סקריפט נוקשה.

## מודל מנטלי: Executor → Manager

> "The goal in an AI-augmented world should be becoming a 'super manager' who coordinates AI tools, not simply a faster individual worker."

**לפני OpenClaw**: אתה הביצועיסט. קופץ לסביבה, פותח עורך, מריץ, בודק, מדווח.

**אחרי OpenClaw**: אתה המנהל. מבטא כוונות דרך קול/צ'אט → AI יוצר פרויקט ותוכנית → דיון → AI מבצע באופן עצמאי.

> "A manager shouldn't get bogged down in specifics—they should focus on the higher-level, abstract work."

## ארכיטקטורת פריסה (4 מודלים)

| מודל | עבור | חסרונות |
|------|------|---------|
| מחשב אישי | ניסויים | רק כשהמחשב דולק |
| שרת בית (Mac Mini, Pi) | שימוש אישי 24/7 | עלות חומרה, נטוורק |
| Cloud VPS | אמינות, נגישות | עלות חודשית, אחריות אבטחה |
| Serverless | אפס עלות במנוחה | מורכבות state |

**עיקרון האבטחה**: ברירת מחדל = localhost בלבד. Tailscale VPN או SSH tunnels לגישה מרחוק. **לעולם לא** חשוף לאינטרנט פתוח.

## מה OpenClaw לא יכול לעשות

- **החלטות עמומות**: חסר שיפוט אסטרטגי אמיתי
- **אינטראקציות רגשיות**: לא מתאים למשא ומתן מורכב
- **תחומים חדשים**: דורש תמיכת skill; לא מאלתר בתחומים לא מוכרים
- **עולם פיזי**: (עדיין) אין ידיים רובוטיות
- **אמינות מלאה**: הזיות ופרשנויות שגויות עדיין קורות
