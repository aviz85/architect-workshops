## 8 Mistakes ל-Avoid (מ-$5 VPS Review)

| # | Problem | Solution |
|---|---------|----------|
| 1 | Too Autonomous | Require plan presentation + approval before action |
| 2 | Questions Trigger Actions | Questions = explanations, NOT actions |
| 3 | Ghosting | Send follow-up — usually resumes immediately |
| 4 | Infinite Loops | Restart OpenClaw / reboot server |
| 5 | Cron Jobs Silent | Sub-agent wakes main session explicitly |
| 6 | Configuration Overload | Change only what blocks workflow |
| 7 | Memory Disappears | Explicit memory-saving triggers always |
| 8 | Token Hemorrhage | Flat-rate subscriptions > pay-per-token |
