# זיכרון ב-OpenClaw - המדריך המלא
**מקור:** velvetshark.com/openclaw-memory-masterclass (Maintainer של הcodebase)

---

## הכלל הזהב

> **"If it's not written to a file, it doesn't exist."**

הוראה שנתת בצ'אט - לא קיימת אחרי compaction. אם לא כתבת לקובץ - הסוכן לא יזכור.

---

## 4 שכבות זיכרון

| שכבה | מה זה | כמה זמן שורד |
|------|--------|--------------|
| **Bootstrap files** | SOUL.md, AGENTS.md וכו' - נטענים בכל session | **לצמיתות** |
| **Session transcript** | היסטוריית השיחה (JSONL) | **חצי-קבוע** (נדחס) |
| **Context window** | מה המודל רואה עכשיו (200K tokens) | **זמני** |
| **Retrieval index** | ניתן לחיפוש, רק אם נכתב לקבצים | **לצמיתות** |

---

## 3 גורמי כשלון נפוצים

1. **Never Stored** - הוראות רק בצ'אט (הכי נפוץ)
2. **Compaction Lost It** - session ארוך גרם לסיכום שמחק פרטים
3. **Pruning Trimmed It** - תוצאות כלים נוקו מה-RAM

---

## Config: Pre-Compaction Memory Flush

הגדרה שמאלצת את הסוכן לשמור לפני שה-context מתמלא:

```json
{
  "agents": {
    "defaults": {
      "compaction": {
        "reserveTokensFloor": 40000,
        "memoryFlush": {
          "enabled": true,
          "softThresholdTokens": 4000,
          "systemPrompt": "Session nearing compaction. Store durable memories now.",
          "prompt": "Write any lasting notes to memory/YYYY-MM-DD.md; reply with NO_REPLY if nothing to store."
        }
      }
    }
  }
}
```

**למה 40,000?** ה-default של 20K נמוך מדי — tool output אחד גדול יכול לעקוף את ה-safety net.

---

## Config: Session Pruning (לאנתרופיק בלבד)

```json
{
  "agents": {
    "defaults": {
      "contextPruning": {
        "mode": "cache-ttl",
        "ttl": "5m"
      }
    }
  }
}
```

**הבדל:** Pruning = זמני, רק tool results, מה-RAM. Compaction = קבוע, מסכם הכל, לדיסק.

## Config: חיפוש Hybrid (מקומי, חינמי)

```json
{
  "agents": {
    "defaults": {
      "memorySearch": {
        "enabled": true,
        "provider": "local",
        "local": {
          "modelPath": "hf:ggml-org/embeddinggemma-300m-qat-q8_0-GGUF/embeddinggemma-300m-qat-Q8_0.gguf"
        },
        "query": {
          "hybrid": {
            "enabled": true,
            "vectorWeight": 0.7,
            "textWeight": 0.3
          }
        }
      }
    }
  }
}
```

Hybrid = BM25 (מילות מפתח) + semantic (משמעות). מוצא "בחרנו בתוכנית ב-$29" כשמחפשים "pricing decisions".

## כללים להוסיף ל-AGENTS.md

```markdown
## Memory Protocol
- לפני תשובה על עבודה קודמת: חפש ב-memory ראשון
- לפני כל משימה חדשה: בדוק memory/תאריך-היום
- כשלמדת משהו חשוב: כתוב לקובץ מיד
- כשתוקנת על טעות: הוסף את התיקון כחוק ב-MEMORY.md
- כש-session גדל: סכם ל-memory/YYYY-MM-DD.md

## Retrieval Protocol
לפני עבודה משמעותית:
1. memory_search על הפרויקט/נושא/העדפת משתמש
2. memory_get אם צריך קטע ספציפי
3. רק אז המשך
```

## מה לשמור איפה

| שמור כאן | אל תשמור |
|----------|----------|
| החלטות, עקרונות, אילוצים | API keys, tokens, סיסמאות |

| העדפות משתמש, תיקונים | טיוטות זמניות |
| כללים "תמיד X, לעולם לא Y" | מחשבות חולפות |

## לוח זמנים לתחזוקת זיכרון

- **יומי:** הוסף ל-daily log (אוטומטי)
- **שבועי:** קדם כללים חשובים מ-daily logs ל-MEMORY.md
- **כלל:** MEMORY.md מתחת ל-100 שורות. זה cheat sheet, לא יומן.

## כלי אבחון

```
/context list       → מה נטען + סטטוס truncation
/context detail     → פירוט עמוק לכל קובץ
/compact [הוראות]   → compaction ידני עם מיקוד
/new או /reset      → session חדש נקי
/verbose            → מצב מילולי לtool calls
```

## תיקונים לכשלונות נפוצים

| בעיה | פתרון |
|------|-------|
| הסוכן שכח העדפות | בדוק MEMORY.md נטען דרך `/context list` |
| memory_search ריק | בדוק שקבצים קיימים; מודל embedding צריך הורדה ראשונה |
| שכח תוצאות כלים | צפוי (session pruning) — כתוב סיכומים לקבצים |
| overflow errors | `/compact` לפני שמתמלא; הגדל `reserveTokensFloor` |
| שכח הכל בלילה | צפוי — reset יומי ב-4:00. חפש memory files להחזרת קונטקסט |
