---

## Global Visual Identity

**Design System — "OpenClaw Universe"**

The entire presentation lives in the visual world of the OpenClaw crab mascot. Every slide shares this universe:

**Color Palette:**
- **Primary Background:** Dark navy (#0F1629) — deep, tech-forward space
- **Secondary Background:** Darker navy (#0A0F1E) — for contrast sections
- **Accent Orange:** Warm coral (#FF6B4A) — matches the crab character, used for headlines, highlights, key elements
- **Accent Green:** Neon mint (#22C55E) — tech elements, code, terminal references, progress indicators
- **Text White:** Off-white (#E8E8F0) — primary text color
- **Text Muted:** Soft gray (#8B8BA3) — secondary text, annotations
- **Highlight Glow:** Soft green glow effect behind key elements — mimics the laptop screen glow from the avatar

**Typography:**
- **Headlines:** Rubik Bold, 54pt, coral (#FF6B4A)
- **Subheadings:** Rubik Medium, 28pt, off-white (#E8E8F0)
- **Body Text:** Rubik Regular, 22pt, off-white (#E8E8F0)
- **Code/Terminal:** JetBrains Mono, 20pt, green (#22C55E)
- **Annotations:** Rubik Light, 16pt, muted gray (#8B8BA3)
- **All text:** RTL, right-aligned unless centered

**Recurring Visual Elements:**
- **The Crab Mascot:** The orange OpenClaw crab appears as a recurring character — sometimes small in corners, sometimes large as the main visual. It reacts to content: holding tools, wearing hats, looking worried, celebrating. Always in the same warm 3D cartoon style as the avatar.
- **Floating Code Particles:** Small green (#22C55E) code snippets, binary digits, and circuit patterns float in backgrounds — matching the avatar's background aesthetic
- **Glowing Laptop:** The crab's laptop with green glow appears as a motif for "tech in action" moments
- **Dark Glass Cards:** Content boxes use a dark glass/frosted effect (rgba(255,255,255,0.05)) with subtle border (rgba(255,255,255,0.1)) — modern, readable
- **Progress Crab Trail:** A subtle crab-footprint trail at the bottom of slides shows progression through the presentation

**Slide Backgrounds:**
- Default: Dark navy (#0F1629) with subtle radial gradient (slightly lighter center)
- Section openers: Darker (#0A0F1E) with larger floating code particles
- Demo slides: Dark with green terminal-style border at top
