## חלק 1: מעובד למנהל (15 דק׳)

### 5. עובד vs מנהל

**ויזואל:** התמונה של עובד מותש מול מנהל מצליח

| עובד | מנהל |
|------|------|
| ממוקד בלעבוד | גורם לדברים לעבוד |
| עושה משימות | מאפשר משימות להיעשות |
| צוואר בקבוק | משחרר צווארי בקבוק |

**הנקודה:** אם רוצים לנצל סוכנים - חייבים לעבור מ"עובד" ל"מנהל".

### 6. סימולציית צווארי הבקבוק

**ויזואל:** סימולציה אינטראקטיבית

- מנהל טוב = משחרר צווארי בקבוק
- מאפשר לעבודה לזרום מקצה לקצה
- הדבר החשוב: להבין **איפה קלוד רץ** ו**באיזה מרחב הוא פועל**
- לתת לו משימה שם, בצורה הכי מלאה שאפשר

### 6.1 דוגמאות לצווארי בקבוק ופתרונות

**צוואר בקבוק 1: להשיג API Key**
```
❌ צוואר בקבוק:
   "תרשם לשירות X ותביא API key"
   → צריך להיכנס לאתר, להירשם, לאמת מייל, להיכנס לדשבורד...

✅ פתרון CLI:
   stripe login → מקבל key מיידית
   gh auth login → GitHub token אוטומטי
   aws configure → הכל דרך הטרמינל
```

**צוואר בקבוק 2: לפתוח קובץ בתוכנה**
```
❌ צוואר בקבוק:
   "תפתח את הקובץ ב-Photoshop ותשנה את הגודל"
   → קלוד לא יכול לפתוח GUI

✅ פתרון CLI:
   magick input.jpg -resize 800x600 output.jpg
   → ImageMagick עושה הכל בשורת פקודה
```

**צוואר בקבוק 3: להעלות לשרת**
```
❌ צוואר בקבוק:
   "תיכנס ל-cPanel ותעלה את הקבצים"

✅ פתרון CLI:
   rsync -avz ./dist/ user@server:/var/www/
   → או: vercel deploy / netlify deploy
```

**צוואר בקבוק 4: לשלוח מייל**
```
❌ צוואר בקבוק:
   "תפתח Gmail ותשלח מייל"

✅ פתרון CLI/API:
   curl -X POST https://api.sendgrid.com/v3/mail/send
   → או: mcp של email
```

### 6.2 CLI Tools שחוסכים חיים

| תחום | GUI | CLI Alternative | יתרון |
