## Key Innovation: Prep Week

Session 1 feedback from Cohort A showed installation is a critical blocker (~1.5 hours wasted). Cohort B solves this with a **prep week** before session 1:

- Pre-recorded installation videos (Mac + Windows)
- Written installation guide (HTML, deployed to GitHub Pages)
- WhatsApp troubleshooting group active during prep week
- Pre-session questionnaire to verify readiness
- Everyone arrives at session 1 **installed and ready**

### Installation Guide Covers

1. Node.js installation (Mac: Homebrew or .pkg, Windows: .msi)
2. Git installation (Mac: Xcode CLI tools, Windows: Git for Windows)
3. Claude Code installation (`npm install -g @anthropic-ai/claude-code`)
4. VS Code setup (default editor, not raw terminal)
5. `cc` shortcut setup
6. Verification checklist
7. Common errors & troubleshooting (PATH, PowerShell vs CMD, "not recognized")

### Pre-Session Questionnaire (Google Form)

Questions in Hebrew:

1. מק או ווינדוז? (Mac or Windows?)
2. יש מנוי קלוד? איזה תוכנית? (Claude subscription? Which plan?)
3. התקנת Claude Code? (Installed Claude Code?)
4. עבדת עם Claude Code? (Worked with Claude Code?)
5. מכיר/ה את הטרמינל? (Familiar with terminal?)
6. התקנת VS Code? (Installed VS Code?)
