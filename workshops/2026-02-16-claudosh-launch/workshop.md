## Overview

Beginner-friendly, hands-on workshop introducing Claude Code from scratch. No prior coding knowledge required. Participants install Claude Code live, learn about AI agents vs. chat tools, explore basic file operations, and understand the CLAUDE.md system prompt concept.

Co-presented with Guy Ronen, a 23-year veteran CS lecturer who serves as "co-pilot" - grounding explanations, managing Q&A, and bridging technical concepts for non-technical participants.

---

## Target Audience

- Complete beginners to Claude Code
- No programming background required
- Need motivation and willingness to learn
- Requires a paid Claude subscription ($20/month minimum)
