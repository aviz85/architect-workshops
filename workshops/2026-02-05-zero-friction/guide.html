מתחילים מהכאב 🎯

לא מתחילים מהכלי — מתחילים מהבעיה.
מה מתיש אתכם? מה לוקח יותר מדי זמן?

  • חשבו על משימה שחוזרת על עצמה כל יום/שבוע
  • משהו שאתם עושים ביד אבל שונאים
  • תהליך שיש בו הרבה שלבים קטנים
🔮 סקיל עזר למציאת הפרוייקט
/find-my-project
שואל על הכאבים מזהה הזדמנויות מציע פרוייקט מציע קבצים
2

יוצרים תיקייה 📁

הפרוייקט צריך בית. תיקייה נפרדת שתכיל את הכל.

📋 איך עושים את זה
  1. פתחו את הטרמינל (או VS Code)
  2. צרו תיקייה חדשה: mkdir ~/projects/my-project
  3. היכנסו אליה: cd ~/projects/my-project
  4. הפעילו את קלוד: claude
💡 טיפ
אפשר פשוט לבקש מקלוד: ״צור לי תיקייה חדשה לפרוייקט ניהול לקוחות״
3

מזינים מידע 📥

הסוכן צריך להכיר את הפרוייקט. העתיקו קבצים רלוונטיים או ספרו לו.

📋 מה להכניס לתיקייה
  1. קבצי אקסל/מסמכים רלוונטיים
  2. דוגמאות של מה שאתם עושים
  3. רשימת לקוחות/משימות/תוצרים
💡 למה קבצי טקסט?
קלוד קורא קבצי טקסט (.md, .txt) בקלות.
הוא יחפש אוטומטית מידע בקבצים — בלי סקריפטים.
4

יוצרים CLAUDE.md 📄

הקובץ הכי חשוב — כאן מלמדים את קלוד מי אתם ומה הפרוייקט.

📋 מה לכתוב ב-CLAUDE.md
  1. מי אתה — שם, עסק, סגנון עבודה
  2. מה הפרוייקט — מטרה, לקוחות, תוצרים
  3. כללים — איך אתה אוהב שדברים ייעשו
  4. מידע קבוע — פרטי התקשרות, תמחור, תבניות
💡 טיפ
אפשר לבקש מקלוד: ״עזור לי לכתוב CLAUDE.md לפרוייקט הזה״ והוא ישאל אתכם שאלות.
שלב ב׳: בניית סקילים
5

הסקיל הראשון ⚡

בוחרים משימה אחת חוזרת — והופכים אותה לסקיל. תוך כדי תנועה.

📋 איך בונים סקיל
  1. עשו את המשימה עם קלוד פעם אחת
  2. בקשו: ״הפוך את מה שעכשיו עשינו לסקיל״
  3. בדקו שהסקיל עובד
  4. שפרו אם צריך
💡 TSK — קיצור דרך
כתבו TSK (Tweak Skill) כדי לבקש מקלוד לעדכן את הסקיל הרלוונטי עם מה שלמדתם עכשיו.
6

ערימות סקילים 📚

סקילים שקוראים לסקילים אחרים. תהליכים שלמים.

  • סקיל ״סגירת עסקה״ = הצעה + חוזה + יומן + ריינדר
  • סקיל ״סוף יום״ = סיכום + משימות + דוח
  • כל סקיל חדש משתמש במה שכבר בנינו
💡 DRY — Don't Repeat Yourself
סקילים = מיקרו-שירותים. אל תשכפלו — הפנו מסקיל אחד לשני.
שלב ג׳: חיבורים לעולם
7

מתחברים לכלים 🔌

וואטסאפ, ג׳ימייל, יומן — סקילים מוכנים מהספרייה.

📋 איך מתקינים סקיל מהספרייה
  1. היכנסו לספריית הסקילים (קישור למעלה)
  2. מצאו סקיל שאתם צריכים
  3. לחצו על ״התקנה״
  4. הריצו את פקודת ההתקנה בקלוד

מחקר חיבורים חדשים 🔍

צריכים חיבור שלא קיים? מחקר משותף עם קלוד.

  • ״תחקור איך להתחבר ל-API של X״
  • קלוד יחפש דוקומנטציה ודוגמאות
  • תבנו יחד את החיבור
שלב ד׳: מתקדם
9

פתרון בעיה → סקיל 🎁

פותרים בעיה בשיחה? מיד אורזים את הפתרון לסקיל.

📋 התהליך
  1. פותרים בעיה דרך שיחה עם קלוד
  2. מזהים את התבנית הכללית
  3. מבקשים: ״ארוז את זה כסקיל״
  4. בפעם הבאה — הסקיל עושה את זה לבד
10

גיבוי עם GitHub 💾

כל פרוייקט מסונכרן ל-GitHub. גיבוי + גרסאות + שיתוף.

📋 הקמה חד-פעמית
  1. פתחו חשבון ב-github.com
  2. התקינו gh CLI: brew install gh
  3. התחברו: gh auth login
  4. בקשו מקלוד: ״צור repo ודחוף את הפרוייקט״
💡 טיפ
ברירת מחדל: private. רק אתם רואים את הקוד.
קלוד יוצר .gitignore אוטומטית — לא ידחוף קבצים רגישים.

מספר פרוייקטים 🌐

אקוסיסטם של פרוייקטים שעובדים יחד. סקילים גלובליים.

  • כל פרוייקט = CLAUDE.md משלו + גישה לגלובליים
