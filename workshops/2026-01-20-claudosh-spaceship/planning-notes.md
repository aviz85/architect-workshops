**Build a quotation system**
1. Create new project (empty folder)

### Part 2: פרויקט תוכן - ~25 min

2. **Demo:** Ask for content → creates enhanced content AND makes PDF in one go!

**Spaceship Mode (Multi-Agent)**
1. What is spaceship mode? (multiple agents in parallel)
2. How to run agents in parallel

4. Best practices and when to use
