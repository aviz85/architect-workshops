מדריך מעשי לבניית Agentic App עם Claude Code

1
יצירת תיקיית הפרויקט

נתחיל ביצירת תיקייה חדשה על שולחן העבודה בשם my-crm:

  1. לחצו קליק ימני על שולחן העבודה
  2. בחרו New → Folder
  3. קראו לתיקייה: my-crm
2
יצירת קיצור דרך ל-Claude Code

ניצור קיצור דרך שיפתח את Claude Code ישירות בתיקייה שלנו:

  1. לחצו קליק ימני על שולחן העבודה
  2. בחרו New → Shortcut
  3. בשדה Location הכניסו:
powershell.exe -NoExit -Command "cd '$env:USERPROFILE\Desktop\my-crm'; claude --dangerously-skip-permissions"
💡 טיפ

משתנה הסביבה $env:USERPROFILE מצביע אוטומטית לתיקיית המשתמש שלכם!

  1. לחצו Next ותנו שם לקיצור: Claude - My CRM
  2. לחצו Finish
3
הגדרת הרשאות מנהל

נגדיר שהקיצור יפעל עם הרשאות מנהל:

  1. לחצו קליק ימני על הקיצור שיצרנו
  2. בחרו Properties
  3. בלשונית Shortcut לחצו על Advanced...
  4. סמנו ✅ Run as administrator
  5. לחצו OK → Apply → OK
💡 למה צריך הרשאות מנהל?

חלק מהפעולות של Claude Code (כמו התקנת packages) דורשות הרשאות גבוהות

4
הורדת נתוני ה-CRM

הורידו את קובץ נתוני הלקוחות לתוך תיקיית my-crm:

📥 הורדת mock_crm_data.xlsx

הקובץ מכיל:

  • לקוחות - 50 לקוחות עם פרטי קשר
  • היסטוריית רכישות - מה כל לקוח קנה
  • תקשורת - היסטוריית שיחות ומיילים
  • פרופיל מורחב - מקצוע, תחומי עניין, ציון
  • משימות - מעקב ותזכורות
  • סטטיסטיקות - סיכום נתונים
⚙️ הגדרת Claude Code
5
הפעלת Claude Code ולמידה על Primitives

פתחו את Claude Code דרך הקיצור שיצרנו, ובקשו ממנו ללמוד על היכולות:

PROMPT 
אני רוצה לבנות "Agentic App" - אפליקציה שמופעלת על ידי Claude Code.

לפני שנתחיל, אני צריך שתלמד על הפרימיטיבים של Claude Code:
1. Skills - מה זה ואיך יוצרים
2. Commands - פקודות מותאמות אישית
3. Agents - סוכנים שרצים ברקע
4. CLAUDE.md - קובץ הכללים

השתמש ב-claude-code-guide agent כדי ללמוד על כל אחד מהם ותן לי סיכום קצר.

Claude Code ישתמש ב-agent פנימי כדי ללמוד על היכולות ויסכם לכם.

6
יצירת CLAUDE.md - קובץ הכללים

ניצור קובץ כללים שילמד את Claude Code איך לעבוד בפרויקט שלנו:

PROMPT 
צור קובץ CLAUDE.md לפרויקט שלנו עם הכללים הבאים:

# My CRM - Business Management System

## Project Overview
מערכת ניהול לקוחות לעסק שמוכר קורסים וסדנאות בתחום ה-AI.

## Data Files
- `mock_crm_data.xlsx` - נתוני לקוחות ורכישות

## Rules
1. כל המסמכים יהיו בעברית
2. עיצוב מקצועי ונקי
3. שמירת קבצים בתיקיית `documents/`

## Claude Code Learning Rule
**חשוב מאוד:** בכל פעם שמדברים על אחד מהנושאים הבאים של Claude Code:
- Skills
- Commands
- Agents
- CLAUDE.md
- Hooks

עליך להשתמש ב-`claude-code-guide` agent כדי לקבל מידע מדויק ועדכני לפני שאתה עונה או מבצע.
🎯 למה זה חשוב?

הכלל האחרון מבטיח שכל פעם ש-Claude Code צריך לעבוד עם הפרימיטיבים שלו, הוא יבדוק קודם את התיעוד העדכני!

🛠️ התקנת כלים
7
התקנת Skill: HTML to PDF

נתקין skill שמאפשר יצירת מסמכי PDF מ-HTML:

PROMPT 
התקן את ה-skill של html-to-pdf מספריית aviz85.

הריצו את הפקודה הבאה בטרמינל:
npx add-skill aviz85/claude-skills-library -s html-to-pdf -y

אחרי ההתקנה, התקן את ה-dependencies:
cd .claude/skills/html-to-pdf && npm install

ואז תסביר לי איך להשתמש ב-skill הזה.

פקודות נוספות שימושיות:

# לראות את כל ה-skills הזמינים בספרייה
npx add-skill aviz85/claude-skills-library --list

# להתקין skill גלובלי (לכל הפרויקטים)
npx add-skill aviz85/claude-skills-library -s html-to-pdf -g
8
יצירת הצעת מחיר ראשונה

נשתמש ב-skill שהתקנו כדי ליצור הצעת מחיר ללקוח מה-CRM:

PROMPT 
קרא את קובץ ה-CRM ומצא לקוח שמתאים לקורס AI למתחילים.

צור לו הצעת מחיר מקצועית בעברית שכוללת:
- פרטי הלקוח
- תיאור המוצר
- מחיר והנחה אפשרית
- תנאי תשלום
- תוקף ההצעה

השתמש ב-html-to-pdf skill כדי ליצור PDF מעוצב.
שמור את הקובץ בתיקיית documents/
9
יצירת Skill מותאם אישית להצעות מחיר

נייצר skill משלנו שייצור הצעות מחיר בדיוק כמו שאנחנו רוצים:

PROMPT 
צור skill חדש בשם "create-quotation" שייצור הצעות מחיר.

לפני שאתה יוצר, השתמש ב-claude-code-guide agent כדי ללמוד איך ליצור skill נכון.

הSkill צריך:
1. לקבל שם לקוח ומוצר
2. לקרוא את פרטי הלקוח מה-CRM
3. ליצור HTML מעוצב עם:
   - כותרת "הצעת מחיר"
   - תאריך ומספר הצעה
   - פרטי לקוח
   - טבלת מוצרים ומחירים
   - סה"כ לתשלום
   - תנאים והגבלות
4. להשתמש ב-html-to-pdf skill ליצירת ה-PDF
5. לשמור בתיקיית documents/quotations/

העיצוב: צבעים ירוקים (#22C55E), פונט נקי, RTL

13
הסוכן שמחבר הכל - המלצות חכמות

זה הרגע הקסום! ניצור agent שמסתכל על ה-CRM ועל המוצרים ומייצר המלצות מותאמות אישית.

חזרו לפרויקט my-crm והפעילו את הפרומפט הבא:

PROMPT 
צור skill חדש בשם "generate-recommendations" שעושה את הדבר הבא:

1. קורא את נתוני הלקוחות מ-mock_crm_data.xlsx
2. קורא את קטלוג המוצרים מתיקיית my-products (השתמש ב-/add-dir להוסיף אותה)
3. לכל לקוח, מנתח:
   - מה הוא כבר קנה (היסטוריית רכישות)
   - מה תחומי העניין שלו (פרופיל מורחב)
   - מה הסטטוס שלו (VIP? ליד חדש?)
4. מייצר המלצות מותאמות אישית:
   - איזה מוצר להציע לו (upsale)
   - הודעת וואטסאפ מותאמת בעברית
   - סיבה להמלצה

לפני שאתה יוצר את ה-skill, השתמש ב-claude-code-guide agent כדי ללמוד איך ליצור skill שמשתמש ב-/add-dir לעבודה חוצת פרויקטים.

הפלט: קובץ recommendations.md עם טבלה של כל הלקוחות וההמלצות שלהם.
🎯 למה זה קסם?

עכשיו יש לנו סוכן שאפשר להפעיל בכל רגע ולקבל המלצות מותאמות אישית לכל לקוח - בהתבסס על מה שהוא קנה ומה שיש לנו להציע!

עכשיו נבדוק שזה עובד:

PROMPT 
/generate-recommendations

הרץ את הסוכן וצור המלצות לכל הלקוחות.
