# פרק 9: תהליכים מורכבים בצ'יק

## מבוא (15 שניות)

עד עכשיו ראינו סקילים בודדים וערימות.
עכשיו נראה את הכוח האמיתי:

**תהליכים שהיו לוקחים שעות - בפקודה אחת.**

---

## הפרומפט שמפיל סוכנים (90 שניות)

### הפרומפט:

```
"שלח לחיים את הצעת המחיר שהוצאנו אתמול,
שלח לו תזכורת עוד 10 דקות בוואצאפ,
תכין את החוזה לקראת שליחה ללקוח אחר,
ותשלח לי את הטיוטה בוואצאפ לאישור."
```

### למה סוכנים אחרים נכשלים?

| מה חסר | למה זה נכשל |
|--------|-------------|
| לא יודע מי חיים | "באיזה CRM? מה המייל?" |
| לא יודע איפה ההצעה | "באיזה תיקייה? מה השם?" |
| לא יכול לשלוח וואצאפ | אין אינטגרציה |
| לא יודע מה "הלקוח האחר" | אין קונטקסט |
| לא יודע לתזמן | אין יכולת scheduling |

### למה Claude Code מצליח?

**כי יש לו:**
- תיקיית `clients/haim/` עם כל הפרטים
- תיקיית `documents/proposals/` עם ההצעות
- אינטגרציית וואצאפ מוגדרת
- ידע מי "הלקוח האחר" (מה-context)
- יכולת להריץ פקודות בזמן

**התוצאה:** פקודה אחת → 4 פעולות → שלם.

---

## דוגמאות מהעולם האמיתי (120 שניות)

### דוגמה 1: השקת סדנה

**הפקודה:**
```
"תשיק את הסדנה של יום חמישי -
פוסטר, פוסט לפייסבוק, הודעה לקבוצת וואצאפ"
```

**מה קורה:**
1. Claude קורא את `workshop.md`
2. יוצר פוסטר עם הפרטים (Gemini)
3. כותב פוסט בסגנון שלכם
4. שולח לקבוצת הוואצאפ
5. מעדכן סטטוס ב-pipeline

**זמן:** 2 דקות במקום שעה.

### דוגמה 2: סגירת חודש

**הפקודה:**
```
"סגור את החודש - דוח הכנסות, רשימת לקוחות פעילים,
ומשימות פתוחות. שלח לי סיכום"
```

**מה קורה:**
1. סורק את כל החשבוניות
2. מחשב סה"כ הכנסות
3. מזהה לקוחות פעילים
4. מושך משימות פתוחות
5. מייצר דוח מעוצב
6. שולח לכם בוואצאפ

### דוגמה 3: הכנה לפגישה

**הפקודה:**
```
"הכן אותי לפגישה עם שרה מחר -
מה עשינו ביחד, מה פתוח, מה להציע"
```

**מה קורה:**
1. קורא את `clients/sarah/history.md`
2. מזהה פרויקטים פתוחים
3. בודק מחירון להצעות רלוונטיות
4. מכין תקציר עם המלצות
5. שומר לפני הפגישה

### דוגמה 4: יצירת תוכן שבועי

**הפקודה:**
```
"הכן את התוכן לשבוע הבא -
3 פוסטים, ניוזלטר, ופוסט בלוג"
```

**מה קורה:**
1. בודק מה פורסם לאחרונה (לא לחזור)
2. מחפש נושאים רלוונטיים
3. כותב 3 פוסטים בסגנון שלכם
4. מכין ניוזלטר
5. כותב פוסט בלוג ארוך
6. שומר הכל בתיקיות המתאימות
7. מציע תאריכי פרסום

**הדרך הלא נכונה:**

2. לכתוב סקיל ענק
3. לגלות שזה לא עובד

**הדרך הנכונה:**

2. לבקש מ-Claude לתעד
3. לבקש מ-Claude להפוך לסקיל
4. לשפר בהדרגה

### דוגמה:

**פעם ראשונה (ידני):**
```
> "שלח מייל לחיים עם הצעת המחיר"
> "שלח לו גם תזכורת בוואצאפ"
> "שמור העתק בתיקייה"
```

**פעם שנייה (בקשה לאוטומציה):**
```
> "תיצור לי סקיל שעושה את התהליך הזה:
   שליחת הצעה + תזכורת + שמירה"
```

**פעם שלישית (שימוש):**
```
> "תשלח הצעה לחיים"
```

## טיפים לתהליכים מורכבים (45 שניות)

### 1. התחילו פשוט
❌ "תעשה לי מערכת CRM מלאה"
✅ "תשלח מייל ותשמור שהמייל נשלח"

### 2. הוסיפו שכבות
אחרי שהבסיס עובד - הוסיפו:
- תזמון
- תזכורות
- דיווחים

### 3. טפלו בשגיאות
```
> "אם המייל לא נשלח - שמור טיוטה ותזכיר לי"
```

### 4. בקשו לוגים
```
> "אחרי כל פעולה - תעדכן את log.md"
```

## סיכום (15 שניות)

תהליכים מורכבים = צירוף של דברים פשוטים.

**הסוד:**
- Context (Claude מכיר את העסק)
- Skills (יודע לעשות כל שלב)
- Integration (מחובר לכלים)

בפרק הבא נדבר על איך ההתייעלות הזו הופכת לאקספוננציאלית.
