# פרק 4: מתחילים להזיז עניינים - Claude Code עובד על הקבצים שלנו

## מבוא (15 שניות)

עכשיו שיש לנו תיקייה ומבנה -
בואו נראה את Claude Code בפעולה.

זה הפרק שבו הקסם מתחיל.

---

## הפעולות הבסיסיות (90 שניות)

### מה Claude Code יכול לעשות עם קבצים?

**1. לקרוא:**
```
"מה כתוב בקובץ clients/haim/profile.md?"
```

**2. ליצור:**
```
"צור קובץ חדש בשם meeting-notes.md עם סיכום הפגישה של היום"
```

**3. לערוך:**
```
"עדכן את הטלפון של חיים ל-050-1234567"
```

**4. להעביר:**
```
"העבר את כל קבצי ה-PDF לתיקיית documents"
```

**5. למחוק:**
```
"מחק את הקבצים הזמניים מהתיקייה"
```

**הכל בעברית. הכל במשפט אחד.**

## הדגמה חיה: יצירת מסמך (90 שניות)

**המשימה:** ליצור הצעת מחיר

**מה אומרים:**
```
"צור הצעת מחיר לחיים כהן על בניית אתר.
המחיר: 5,000 ש"ח.
כלול תיאור של מה כלול בעבודה."
```

**מה Claude עושה:**
1. קורא את פרטי חיים (אם קיימים)
2. קורא את תבנית הצעות המחיר (אם קיימת)
3. יוצר מסמך מעוצב
4. שומר במקום הנכון

**התוצאה:** קובץ מוכן תוך שניות.

### הבונוס:

```
"עכשיו תהפוך את זה ל-PDF"
```

Claude ממיר את המסמך ל-PDF.
**בלי לפתוח Word. בלי להתעסק עם פורמטים.**

Claude קורא את כל הקבצים הרלוונטיים ומפיק דוח.

**חיפוש רגיל (Ctrl+F):**

- מבין מההקשר מי מתעניין

## דוגמאות מהחיים (90 שניות)

### דוגמה 1: ניהול לקוחות

```
"מי הלקוחות שלא שילמו עדיין?"
```

```
"שלח תזכורת תשלום לכל מי שחייב יותר מ-30 יום"
```

### דוגמה 2: הכנה לפגישה

```
"הכן לי סיכום על חיים לפני הפגישה מחר.
מה עשינו ביחד? מה היו הבעיות? מה לדבר עליו?"
```

### דוגמה 3: ניתוח

```
"כמה הכנסה היתה לי החודש הזה לעומת חודש שעבר?"
```

### דוגמה 4: יצירת תוכן

```
"כתוב פוסט ללינקדאין על השירות החדש שאני מציע"
```

**שימו לב:** כל הדוגמאות מתבססות על המידע שכבר יש בתיקייה.
לא צריך להעתיק-להדביק כלום.

## טיפים לעבודה יעילה (45 שניות)

### 1. היו ספציפיים

❌ "תעשה משהו עם הלקוחות"
✅ "צור רשימה של לקוחות שלא פנינו אליהם חודש"

### 2. תנו הקשר

❌ "שלח מייל"
✅ "שלח מייל תזכורת לחיים על הפגישה מחר ב-10:00"

### 3. בקשו לראות לפני ביצוע

✅ "הראה לי טיוטה לפני ששולח"
✅ "תציג לי את השינויים לפני שמיישם"

### 4. השתמשו ב"אל תעשה"

✅ "עדכן את הקובץ אבל אל תמחק את ההערות הקיימות"
