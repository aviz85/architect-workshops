## שלב 1: חיבור Gmail (90 שניות)

### אפשרות A: Google Apps Script (מומלץ)

**1. צרו פרויקט חדש:**
```
script.google.com → New Project
```

**2. קוד לקריאת מיילים:**
```javascript
function doGet(e) {
  const threads = GmailApp.getInboxThreads(0, 10);
  const emails = threads.map(thread => {
    const msg = thread.getMessages()[0];
    return {
      id: msg.getId(),
      from: msg.getFrom(),
      subject: msg.getSubject(),
      body: msg.getPlainBody().substring(0, 500),
      date: msg.getDate()
    };
  });
  return ContentService.createTextOutput(JSON.stringify(emails));
}
```

**3. קוד לשליחת מיילים:**
```javascript
function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  GmailApp.sendEmail(data.to, data.subject, data.body);
  return ContentService.createTextOutput("Sent");
}
```

**4. פרסום:**
- Deploy → Web App
- Execute as: Me
- Access: Anyone

**5. שמירת ה-URL בסקיל**

```markdown
3. הצג: שולח, נושא, תקציר

## פורמט הפלט

- **מאת:** [שם ומייל]
- **נושא:** [subject]
- **תקציר:** [2-3 משפטים]
- **דחיפות:** [גבוהה/בינונית/נמוכה]
- **סוג:** [לקוח/פנייה/ספאם/אחר]
```

### הסקיל המאחד:

```markdown
"תטפל במיילים", "תקרא את התיבה"

1. הפעל read-email - קבל רשימת מיילים
```
