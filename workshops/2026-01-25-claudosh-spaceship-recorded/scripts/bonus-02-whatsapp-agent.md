# בונוס 2: סוכן וואצאפ מהידע שלכם

## מה נבנה? (30 שניות)

סוכן שעונה בוואצאפ על סמך הידע הארגוני שלכם.
לקוח שואל שאלה → מקבל תשובה מדויקת → בלי שתתערבו.

**התוצאה:**
בוט וואצאפ שמכיר את העסק שלכם לפרטי פרטים.

---

## הרעיון (60 שניות)

### הבעיה עם בוטים רגילים:

- תשובות גנריות
- לא מכירים את העסק
- צריך לתכנת כל תשובה מראש

### הפתרון שלנו:

**Knowledge Base + Claude = בוט חכם**

הבוט לא עונה מתבניות.
הוא **מחפש בידע שלכם** ו**מנסח תשובה מותאמת**.

### איך זה עובד:

1. לקוח שולח הודעה בוואצאפ
2. ההודעה מגיעה ל-Claude
3. Claude מחפש בקבצי הידע שלכם
4. מנסח תשובה בסגנון שלכם
5. שולח חזרה ללקוח

## שלב 2: חיבור וואצאפ (60 שניות)

### אפשרות A: Green API

**1. הרשמה:**
```
green-api.com → Create Account
```

**2. חיבור הטלפון:**
- סרקו QR code
- וואצאפ מחובר!

**3. קבלת credentials:**
```
Instance ID: 1234567890
API Token: abc123xyz...
```

### אפשרות B: WAHA (Self-hosted)

**1. התקנה עם Docker:**
```bash
docker run -d -p 3000:3000 devlikeapro/waha
```

**2. סריקת QR דרך הממשק**

**3. שימוש ב-API:**
```
http://localhost:3000/api/sendMessage
```

## שלב 3: סקיל מענה (90 שניות)

```markdown
# answer-query

## מטרה
לענות לשאלות מלקוחות על סמך מאגר הידע.

## תהליך
1. קרא את השאלה מהלקוח
2. חפש בקבצי knowledge/ תשובה רלוונטית
3. אם מצאת - נסח תשובה בסגנון העסק
4. אם לא מצאת - העבר לאדם (escalate)

## כללי ניסוח
- קצר ותכליתי (וואצאפ!)
- ידידותי אבל מקצועי
- תמיד לסיים עם "יש עוד שאלות?"
- להשתמש באימוג'ים במידה 👍

## מה לא לעשות
- לא להמציא מידע
- לא לתת מחירים שלא במאגר
- לא להבטיח דברים שלא בסמכות
- לא לענות על נושאים רגישים (להעביר לאדם)

## escalation
אם אחד מאלה - תעביר לאדם:
- שאלה על מחיר לא סטנדרטי
- תלונה
- בקשה דחופה
- משהו שלא במאגר הידע
```

## שלב 4: Webhook (60 שניות)

### מה זה Webhook?

דרך לקבל הודעות אוטומטית כשמגיעה הודעה חדשה.

### הגדרה ב-Green API:

```
Settings → Webhooks → Incoming Message URL
```

### מה קורה:

1. לקוח שולח הודעה
2. Green API שולח ל-webhook שלכם
3. Claude מקבל את ההודעה
4. Claude עונה
5. התשובה חוזרת ללקוח

### לצורך הקורס:

אפשר גם לעבוד ב-polling (לבדוק כל X שניות אם יש הודעות חדשות).
