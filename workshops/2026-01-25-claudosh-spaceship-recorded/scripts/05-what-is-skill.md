# פרק 5: מה זה סקיל, ואיך הוא עובד

## מבוא (15 שניות)

עד עכשיו Claude עשה מה שביקשנו.
אבל כל פעם הייתם צריכים להסביר בדיוק מה רוצים.

מה אם Claude היה יודע את ה"איך" מראש?

**זה בדיוק מה שסקיל עושה.**

---

**בוקר:**
```

תשתמש בלוגו שלי, בצבעים הירוקים,
תוסיף תנאי תשלום, תקופת תוקף..."

```

**הבעיה:** אותן הנחיות. שוב ושוב.

## הפתרון: Skill (60 שניות)

### מה זה Skill?

**Skill = הנחיות ארוזות**

במקום להסביר כל פעם מחדש,
אתם אורזים את ההנחיות פעם אחת,
ו-Claude משתמש בהן בכל פעם שצריך.

### האנלוגיה:

**בלי Skill:** עובד חדש ביום הראשון
- צריך להסביר לו הכל
- כל משימה מתחילה מאפס
- לא יודע את ה"איך" שלכם

**עם Skill:** עובד ותיק של 10 שנים
- כבר יודע את הסגנון
- יודע את הכללים
- עושה את זה "בדרך שלכם"

---

## איך Skill נראה? (90 שניות)

### הקובץ הפשוט:

Skill הוא פשוט קובץ טקסט.
לרוב נקרא `SKILL.md` או `instructions.md`.

**דוגמה - Skill להצעות מחיר:**

```markdown
# יצירת הצעת מחיר

## מתי להשתמש
כשהמשתמש מבקש ליצור הצעת מחיר או quote.

## כללים
1. השתמש בלוגו מ-assets/logo.png
2. צבעים: ירוק #22C55E, אפור כהה
3. כתוב בעברית, RTL
4. הוסף תנאי תשלום: 50% מקדמה, 50% בסיום
5. תוקף ההצעה: 14 יום

## פורמט הפלט
- צור קובץ HTML מעוצב
- המר ל-PDF
- שמור בתיקיית documents/proposals/

## מה לכלול
- שם הלקוח ופרטים
- תיאור העבודה
- טבלת מחירים
- סה"כ כולל מע"מ
- תנאים והגבלות
```

**וזהו.** פעם אחת כתבתם, תמיד עובד.

## איך משתמשים ב-Skill? (60 שניות)

### הדרך הפשוטה:

פשוט לבקש את מה שרוצים!

```
"תכין הצעת מחיר לחיים"
```

Claude:
1. מזהה שזו בקשה להצעת מחיר
2. מוצא את הסקיל המתאים
3. עוקב אחרי ההנחיות
4. מייצר תוצאה בדיוק כמו שהגדרתם

### הדרך המפורשת:

אפשר גם לקרוא לסקיל ישירות:

```
/create-proposal לחיים כהן, אתר תדמית, 5000
```

---

## מה הופך Skill לטוב? (60 שניות)

### 1. ספציפי

❌ "צור מסמך יפה"
✅ "צור PDF עם הלוגו בפינה ימנית עליונה, גודל 50px"

### 2. מכסה edge cases

✅ "אם אין מע"מ - כתוב 'פטור ממע״מ'"
✅ "אם המחיר מעל 10,000 - הוסף אפשרות לתשלומים"

### 3. כולל דוגמאות

```markdown
## דוגמה
Input: "הצעה לחיים על אתר"
Output: documents/proposals/proposal-haim-website.pdf
```

### 4. מתאר את "למה"

```markdown
## מטרה
ליצור הצעות מחיר מקצועיות שמרשימות לקוחות
ושומרות על עקביות מותגית.
```

**בקשו מ-Claude ליצור Skill:**

"צור לי Skill לכתיבת פוסטים לרשתות חברתיות.

הכללים:
- עברית, קליל ומקצועי
- אורך 100-200 מילים
- כולל קריאה לפעולה

Claude ייצור את הקובץ במקום הנכון.

**מעכשיו:**
```
"כתוב פוסט על השירות החדש שלי"
```

Claude ישתמש בכללים שהגדרתם.

## סיכום (15 שניות)

**Skill = ניסיון ארוז**

- פעם אחת מגדירים את הכללים
- תמיד מקבלים תוצאה עקבית
- לא צריך להסביר מחדש כל פעם

בפרק הבא נלמד לבנות ערימות של סקילים - כוח אמיתי.
