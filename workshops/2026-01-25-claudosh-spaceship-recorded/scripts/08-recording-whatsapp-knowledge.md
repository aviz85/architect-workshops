# פרק 8: סקיל הקלטה, וואצאפ וידע ארגוני

## מבוא (15 שניות)

בפרק הזה נראה שלושה סקילים שמשנים את המשחק:
- **הקלטה** - ללכוד רעיונות תוך כדי תנועה
- **וואצאפ** - לתקשר ישירות עם לקוחות
- **ידע ארגוני** - לגרום ל-Claude להכיר את העסק שלכם

---

## סקיל הקלטה / Memo (90 שניות)

### הבעיה:

יש לכם רעיון בנהיגה.
פגישה מעניינת שרוצים לתעד.
שיחת טלפון שצריך לסכם.

**מה עושים?**
- שוכחים
- רושמים בקיצור ואז לא מבינים
- מקליטים ואף פעם לא מאזינים

### הפתרון: סקיל Memo

**מה הוא עושה:**
1. מקליט הודעה קולית
2. מתמלל אוטומטית
3. מסכם את הנקודות העיקריות
4. שומר במקום הנכון

**איך משתמשים:**

```
> /memo
[מקליט...]
"היה לי רעיון מטורף לסדנה הבאה -
לעשות את כל ההדגמות בזמן אמת,
בלי שקופיות, רק טרמינל על המסך..."
[עוצר]
```

**התוצאה:**
```markdown
# Memo - 2026-01-25 14:32

## סיכום
רעיון לסדנה: הדגמות בזמן אמת בלי שקופיות

## פרטים
- כל ההדגמות בטרמינל
- בלי מצגת
- יותר אותנטי ומרשים

## תגיות
#סדנה #רעיון #פורמט
```

**למה זה כוח-על?**
- לא שוכחים רעיונות
- הכל מתועד ומחופש
- Claude יכול לחזור למידע הזה בהמשך

---

## וואצאפ כערוץ תקשורת (90 שניות)

### למה וואצאפ?

- 98% מישראל משתמשים בוואצאפ
- פתיחות גבוהה יותר ממייל
- תחושה אישית יותר

### מה Claude יכול לעשות?

**1. לשלוח הודעות:**
```
> "שלח לחיים בוואצאפ תזכורת על הפגישה מחר ב-10"
```

**2. לשלוח להרבה אנשים:**
```
> "שלח לכל הלקוחות מהחודש הודעת תודה"
```

**3. לשלוח קבצים:**
```
> "שלח לשרה את הצעת המחיר בוואצאפ"
```

**4. הודעות קוליות:**
```
> "הקלט הודעה קולית לחיים עם סיכום הפרויקט"
```

### האינטגרציה:

**Green API** או **WAHA** - שניהם עובדים.
מחברים פעם אחת → עובד לנצח.

### דוגמה מהחיים:

```
> "אחרי כל סדנה, שלח למשתתפים הודעת תודה
   עם קישור להקלטה וחומרים"
```

Claude:
1. מושך את רשימת המשתתפים
2. מכין הודעה מותאמת
3. שולח לכל אחד
4. מתעד ששלח

**אוטומציה של follow-up = יותר לקוחות חוזרים.**

## ידע ארגוני - הלב של הסוכן (90 שניות)

### מה זה "ידע ארגוני"?

כל מה ש-Claude צריך לדעת כדי לעבוד בשבילכם:

- מי אתם ומה העסק
- מי הלקוחות
- איך אתם עובדים
- מה ההעדפות שלכם
- מה הכללים

### איפה שומרים את זה?

**1. CLAUDE.md - הקובץ הראשי**
```markdown
# העסק שלי

## מי אני
שם: ישראל ישראלי
עסק: ייעוץ עסקי
התמחות: סטארטאפים

## סגנון התקשורת
- פורמלי אבל חם
- תמיד לסיים עם CTA
- להשתמש בשם הלקוח

## כללים
- לא לשלוח הודעות אחרי 21:00
- תמיד לאשר לפני שליחה ללקוח
- לשמור עותק של כל מסמך
```

**2. תיקיות מאורגנות**
```
my-business/
├── clients/        # כל הלקוחות
├── templates/      # תבניות
├── products/       # מה מוכרים
└── knowledge/      # מידע נוסף
    ├── pricing.md
    ├── faq.md
    └── processes.md
```

**3. קבצי ידע ספציפיים**

```markdown
# knowledge/pricing.md

## מחירון שירותים

| שירות | מחיר | הערות |
|-------|------|-------|
| ייעוץ שעתי | ₪400 | מינימום שעתיים |
| פרויקט קטן | ₪3,000 | עד שבוע |
| פרויקט גדול | ₪10,000+ | לפי הצעה |
```

### למה זה קריטי?

**בלי ידע ארגוני:**
> "צור הצעת מחיר"
> → Claude שואל 20 שאלות

**עם ידע ארגוני:**
> "צור הצעת מחיר לחיים על ייעוץ"
> → Claude יוצר הצעה מושלמת מיד

---

## איך בונים ידע ארגוני? (60 שניות)

### שלב 1: התחילו מ-CLAUDE.md

```
> "עזור לי ליצור CLAUDE.md לעסק שלי.
   אני עוסק בייעוץ עסקי לסטארטאפים."
```

Claude ישאל שאלות ויבנה את הקובץ.

### שלב 2: הוסיפו בהדרגה

כל פעם שמשהו חסר - הוסיפו:
- "Claude לא ידע את המחיר" → הוסיפו מחירון
- "Claude לא הכיר את הלקוח" → הוסיפו תיקיית לקוחות
- "Claude שאל על הסגנון" → הוסיפו הנחיות סגנון

### שלב 3: תחזוקה

פעם בחודש:
```
> "עבור על ה-CLAUDE.md ועל תיקיית knowledge.
   יש משהו לא מעודכן? חסר משהו?"
```
