# פרק 3: הבית של הפרויקט - התיקייה

## מבוא (15 שניות)

בפרק הזה נבין את העיקרון הכי חשוב של Claude Code:

**פרויקט = תיקייה**

זה נשמע פשוט, אבל זה משנה הכל.

---

## למה תיקייה? (60 שניות)

### הבעיה הישנה:

נניח שיש לכם עסק של ייעוץ.
יש לכם לקוחות, הצעות מחיר, חוזים.

**איפה כל המידע הזה נמצא היום?**

- קצת ב-Google Drive
- קצת ב-WhatsApp
- קצת בראש
- קצת באקסל
- קצת במיילים

**התוצאה:** כל פעם שרוצים לעשות משהו - מחפשים.

### הפתרון:

**הכל בתיקייה אחת.**

```
my-business/
├── clients/
│   ├── haim/
│   │   ├── info.md
│   │   └── proposals/
│   └── sarah/
├── templates/
├── contracts/
└── CLAUDE.md
```

**Claude Code יושב על התיקייה הזו.**
הוא רואה הכל. הוא מכיר הכל.

---

## איך זה עובד בפועל? (60 שניות)

### הדגמה:

נניח שאני רוצה לשלוח הצעת מחיר לחיים.

**בלי Claude Code:**
1. פותח Google Docs
2. מחפש תבנית
3. מעתיק פרטים של חיים
4. מחפש במיילים מה דיברנו
5. יוצר PDF
6. שולח במייל

**עם Claude Code:**
```
"תשלח לחיים הצעת מחיר על פרויקט האתר"
```

**Claude:**
- יודע מי זה חיים (מתיקיית clients/haim/)
- יודע מה הפרויקט (מהיסטוריית השיחות)
- יודע את הסגנון שלי (מהתבניות)
- יוצר ושולח

**שורה אחת במקום 20 דקות.**

---

## מבנה התיקייה האידיאלי (90 שניות)

### העקרונות:

1. **כל דבר במקום שלו** - לקוחות בתיקיית לקוחות
2. **שמות ברורים** - לא "doc1.pdf" אלא "proposal-haim-website.pdf"
3. **מידע נגיש** - טקסט, לא תמונות של טקסט

### דוגמה לעסק:

```
my-business/
│
├── CLAUDE.md              # הגדרות הפרויקט (נלמד בהמשך)
│
├── clients/               # כל הלקוחות
│   ├── haim-cohen/
│   │   ├── profile.md     # מי זה, מה העסק שלו
│   │   ├── contact.md     # טלפון, מייל
│   │   ├── history.md     # מה עשינו ביחד
│   │   └── proposals/     # הצעות מחיר
│   │
│   └── sarah-levi/
│       └── ...
│
├── templates/             # תבניות
│   ├── proposal.md        # תבנית הצעת מחיר
│   ├── contract.md        # תבנית חוזה
│   └── email-welcome.md   # תבנית מייל פתיחה
│
├── products/              # מה אתם מוכרים
│   ├── website-basic.md
│   └── consulting-hour.md
│
└── documents/             # מסמכים שנוצרו
    └── proposals/
        └── 2026-01/
```

## איך Claude Code משתמש בזה? (60 שניות)

### משל הארון:

דמיינו שהסוכן שלכם נכנס למשרד חדש.
הארון מלא בתיקיות מסודרות.

**מה הוא עושה?**
- פותח את הארון
- מסתכל מה יש
- מבין את המבנה
- עכשיו הוא יודע איפה הכל

**Claude Code עושה בדיוק את זה.**

כשאתם פותחים אותו בתיקייה:
1. הוא סורק את המבנה
2. קורא קבצים רלוונטיים
3. מבין את ההקשר
4. מוכן לעבוד

**ככל שהתיקייה מאורגנת יותר - Claude עובד טוב יותר.**

---

## טיפים למבנה טוב (45 שניות)

### עשה:
- ✅ קבצי Markdown (.md) - טקסט פשוט
- ✅ שמות באנגלית (לעקביות)
- ✅ תיקיות לפי נושא
- ✅ תבניות לדברים חוזרים

### אל תעשה:
- ❌ קבצי Word/PDF למידע שצריך לערוך
- ❌ שמות עם רווחים ("הצעת מחיר לחיים.pdf")
- ❌ הכל בתיקייה אחת
- ❌ מידע רק בתמונות

### טיפ זהב:
**התחילו קטן.**
לא צריך לארגן את כל העסק היום.
התחילו עם תיקיית לקוחות.
הוסיפו בהדרגה.
