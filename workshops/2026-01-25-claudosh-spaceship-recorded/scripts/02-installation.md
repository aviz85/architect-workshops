## שלב 4: ההגדרה הכי חשובה - הקיצור (90 שניות)

עכשיו נגדיר קיצור שיחסוך לכם הקלדה.
במקום לכתוב כל פעם את הפקודה המלאה,
נכתוב רק `cc`.

### Mac/Linux:

פתחו את קובץ ההגדרות:
```bash
nano ~/.zshrc
```

הוסיפו בסוף:
```bash
alias cc="claude --dangerously-skip-permissions"
```

שמרו (Ctrl+X, Y, Enter) וטענו מחדש:
```bash
source ~/.zshrc
```

### Windows (PowerShell):

```powershell
notepad $PROFILE
```

הוסיפו:
```powershell
function cc { claude --dangerously-skip-permissions }
```

שמרו וסגרו את PowerShell ופתחו מחדש.

## מה זה "dangerously-skip-permissions"? (30 שניות)

השם נשמע מפחיד, אבל בפועל:

**בלי הדגל הזה:**
- Claude עוצר ומבקש אישור על כל פעולה
- "אתה בטוח שאני יכול לקרוא את הקובץ?"
- "אתה בטוח שאני יכול לשמור?"
- עובד לאט, מעצבן

**עם הדגל:**
- Claude עובד ברצף
- כמו עובד שסומכים עליו
- לא שואל על כל צעד

**זה לא מסוכן.** Claude לא מוחק קבצים חשובים.
הוא פשוט עובד יותר חלק.

## פתרון בעיות נפוצות (45 שניות)

### "command not found: claude"
- סגרו את הטרמינל ופתחו מחדש
- ודאו שה-npm install הצליח

### "command not found: cc"
- ודאו ששמרתם את הקובץ הנכון
- Mac: `~/.zshrc`
- Windows: Profile ב-PowerShell

### "Permission denied"
- ב-Mac: הוסיפו `sudo` לפני הפקודה
- ב-Windows: הריצו PowerShell כ-Administrator

### עדיין לא עובד?
- גוגלו את השגיאה
- או שאלו בקהילה
