# פרק 11: מצב חללית

## מבוא (15 שניות)

הגענו לנקודה שבה הכל מתחבר.

**מצב חללית** = כשאתם יושבים בתא הפיקוד,
ו-Claude טס בשבילכם.

---

## מה זה מצב חללית? (60 שניות)

### האנלוגיה:

**נהיגה רגילה:**
- אתם אוחזים בהגה
- כל פנייה - אתם מחליטים
- כל האטה - אתם מבצעים

**חללית עם אוטופיילוט:**
- אתם קובעים את היעד
- החללית טסה לבד
- אתם מתערבים רק כשצריך

### בעולם של Claude Code:

**מצב רגיל:**
```
> "שלח מייל"
[Claude שואל אישור]
> "כן"
> "עכשיו PDF"
[Claude שואל אישור]
> "כן"
```

**מצב חללית:**
```
> "תטפל בכל הלידים מהיום"
[Claude עובד... עובד... עובד...]
[מודיע כשסיים]
```

---

## איך מפעילים? (60 שניות)

### הדגל הקסום:

```bash
claude --dangerously-skip-permissions
```

או בקיצור (אם הגדרתם):
```bash
cc
```

### מה זה עושה?

**בלי הדגל:**
- Claude עוצר ומבקש אישור על כל פעולה
- "אתה בטוח שאני קורא את הקובץ?"
- "אתה בטוח שאני שומר?"
- עובד לאט, הרבה קליקים

**עם הדגל:**
- Claude עובד ברצף
- לא עוצר על כל צעד
- מודיע כשסיים או כשיש בעיה

### למה השם "dangerously"?

**זה לא באמת מסוכן!**

השם הוא אזהרה שאתם נותנים אמון.
כמו להעביר מישהו מ"עובד חדש" ל"עובד ותיק שסומכים עליו".

Claude לא מוחק קבצי מערכת.
הוא פשוט עובד בלי לשאול כל שנייה.

---

## ריצה אוטונומית ארוכה (90 שניות)

### הכוח האמיתי:

Claude יכול לרוץ חצי שעה, שעה, אפילו יותר.
אתם עושים משהו אחר.
הוא עושה את העבודה.

### דוגמה מהחיים:

```
> "יש לי 50 לידים חדשים בקובץ leads.csv.
   לכל אחד:
   1. צור תיקיית לקוח
   2. הכן הצעת מחיר מותאמת
   3. שלח מייל הקדמה
   4. שמור ב-log מה נעשה"
```

**Claude עובד...**
- 5 דקות...
- 10 דקות...
- 15 דקות...

**"סיימתי. טיפלתי ב-48 לידים (2 עם שגיאות במייל - ראה log)"**

### למה זה משנה את המשחק?

**קודם:**
- 50 לידים × 10 דקות = 8 שעות עבודה

**עכשיו:**
- הפעלתם את Claude
- הלכתם לקפה
- חזרתם - סיים

---

## מתי להשתמש במצב חללית? (45 שניות)

### כן - מתאים:

✅ עיבוד batch של הרבה פריטים
✅ תהליכים שאתם סומכים עליהם
✅ משימות שעשיתם פעמים רבות
✅ כשאתם רוצים לעשות משהו אחר בינתיים

### לא - עדיין לא:

❌ תהליך חדש שלא ניסיתם
❌ משהו עם השלכות שלא ניתנות לביטול
❌ כשיש ספק אם התהליך נכון

### הכלל:

**קודם ידני → אז אוטונומי**

נסו את התהליך עם אישורים.
כשזה עובד - הפעילו מצב חללית.

---

## הכנה למצב חללית (60 שניות)

### 1. Skills מוגדרים היטב

לא "תעשה מה שנראה לך"
אלא "תעקוב אחרי הסקיל create-proposal"

### 2. Error handling

```markdown
## אם משהו נכשל:
- רשום ב-errors.log
- המשך לפריט הבא
- דווח בסוף כמה נכשלו
```

### 3. לוגים ודיווחים

```markdown
## אחרי כל פעולה:
- עדכן את progress.md
- כשמסיים הכל - שלח סיכום
```

### 4. גבולות ברורים

```markdown
## מגבלות:
- מקסימום 100 פריטים בריצה
- אם יותר מ-10% שגיאות - עצור ודווח
- לא לשלוח מיילים אחרי 21:00
```
