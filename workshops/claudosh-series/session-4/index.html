🤖 זרוע האוטונומיה
קונספט הדגמה

הסוכן לא חייב לשבת על המחשב שלכם. הוא יכול לרוץ לבד, בכל מקום, כל הזמן.

  • הוסטינג: VPS (Contabo, Hostinger), GitHub Pages, Vercel — הסוכן מפרסם ומתחזק
  • Agent SDK: הפעלה פרוגרמטית — בנו UI, בנו בוט, בנו אוטומציה
  • Cron Jobs: תזמון משימות — הסוכן רץ כל בוקר, כל שעה, כל שבוע. בלי שתהיו שם
  • Hooks: פעולות אוטומטיות שמופעלות בתגובה לאירועים
  • Background agents: סוכנים שרצים ברקע בזמן שאתם עושים משהו אחר
🔒 אבטחה — נושא קריטי באוטונומיה

ככל שהסוכן יותר אוטונומי — האבטחה יותר חשובה. כמה עקרונות:

  • MCP במקום CLI: במקום לתת לסוכן גישה לכל ה-CLI, תנו לו כלי ספציפי דרך MCP — מצמצם סיכונים, מגדיר בדיוק מה מותר
  • VPS ייעודי: לעולם לא על המחשב האישי — שרת נפרד עם Tailscale VPN
  • הרשאות מינימליות: כל סוכן מקבל רק את הכלים שהוא צריך, לא יותר
🔌 MCP — כלי ספציפי במקום CLI

MCP = Model Context Protocol. במקום לתת לסוכן גישה חופשית לשורת פקודה, מחברים אותו לכלי ספציפי שעושה דבר אחד ויחיד. דוגמה: כלי MCP לדפדפן שיודע רק לנווט ולקרוא — בלי לגעת בקבצים.
