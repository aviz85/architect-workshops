התקנת Node.js

Node.js הוא הבסיס ש-Claude Code רץ עליו. צריך גרסה 18 ומעלה.

אפשרות א׳ — הורדה ישירה (מומלץ למתחילים)

נכנסים לאתר הרשמי ומורידים את הגרסה ל-Mac:

nodejs.org — לחצו על הכפתור הירוק "LTS" והתקינו.

אפשרות ב׳ — דרך Homebrew (למי שמכיר)

אם יש לכם Homebrew מותקן:

brew install node

הורדה והתקנה

נכנסים לאתר הרשמי ומורידים:

nodejs.org — לחצו על "LTS", הורידו את קובץ ה-.msi והריצו אותו.

⚠

חשוב: במהלך ההתקנה, ודאו שהאפשרות "Add to PATH" מסומנת. בלי זה, הטרמינל לא יזהה את הפקודות.

בדיקה שההתקנה הצליחה

פתחו טרמינל (Mac: Terminal, Windows: PowerShell) והריצו:

node --version
# צריך להופיע משהו כמו:
v22.x.x
✓

אם מופיע מספר גרסה (18 ומעלה) — עברתם את השלב הזה.

התקנת Git

Git מנהל גרסאות של קבצים. Claude Code צריך אותו כדי לעבוד עם פרויקטים.

ב-Mac — בדרך כלל כבר מותקן

ב-Mac רוב הסיכויים ש-Git כבר קיים. בדקו:

git --version

אם מופיעה הודעה על התקנת "Command Line Tools" — אשרו את ההתקנה וחכו שתסתיים.

הורדה והתקנה

הורידו מהאתר הרשמי:

git-scm.com — הריצו את ההתקנה עם הגדרות ברירת מחדל.

⚠

חשוב: במסך "Adjusting your PATH" — בחרו באפשרות "Git from the command line and also from 3rd-party software".

בדיקה

git --version
# צריך להופיע משהו כמו:
git version 2.x.x

התקנת Claude Code

זה הסוכן עצמו. ההתקנה לוקחת דקה.

דרישה מקדימה: מנוי Claude

צריך מנוי פעיל ב-claude.ai (תוכנית Pro — $20 לחודש, או Max — $100).

ℹ

אם עדיין אין לכם מנוי — הירשמו כאן. בחרו בתוכנית Pro ($20/חודש).

התקנה

פתחו טרמינל והריצו:

npm install -g @anthropic-ai/claude-code

הפעלה ראשונה

אחרי ההתקנה, צרו תיקייה והריצו:

mkdir ~/my-first-project
cd ~/my-first-project
claude

בפעם הראשונה — ייפתח דפדפן לאימות עם חשבון Claude שלכם. אשרו את החיבור.

✓

אם נפתח ממשק שיחה בטרמינל עם הודעת ברוכים הבאים — Claude Code מותקן ועובד!

התקנת VS Code

VS Code הוא עורך הקוד שנעבוד בו. יש לו טרמינל מובנה — הרבה יותר נוח מהטרמינל הרגיל.

הורדה והתקנה

הורידו מהאתר הרשמי:

code.visualstudio.com — לחצו Download והתקינו.

פתיחת טרמינל ב-VS Code

אחרי ההתקנה:

  1. פתחו את VS Code
  2. מהתפריט העליון: Terminal → New Terminal
  3. או בקיצור מקלדת: Ctrl+` (Windows) / Cmd+` (Mac)
  4. בטרמינל שנפתח למטה — הריצו claude

הגדרת PowerShell כברירת מחדל

ב-VS Code, ודאו שהטרמינל משתמש ב-PowerShell:

  1. ליד שם הטרמינל למטה — לחצו על החץ הקטן
  2. בחרו PowerShell

קיצור cc

במקום לכתוב claude כל פעם — נגדיר קיצור cc.

הגדרת הקיצור

הריצו בטרמינל:

echo 'alias cc="claude"' >> ~/.zshrc
source ~/.zshrc

עכשיו אפשר לכתוב cc במקום claude.

הגדרת הקיצור ב-PowerShell

הריצו בטרמינל:

# פתיחת קובץ הפרופיל
if (!(Test-Path $PROFILE)) { New-Item -Path $PROFILE -Force }
Add-Content $PROFILE 'Set-Alias cc claude'
. $PROFILE

בדיקה

cc --version
# צריך להופיע מספר גרסה

תקלות נפוצות

נתקלתם בבעיה? כנראה שמישהו כבר עבר את זה. הנה הפתרונות:

"node" / "npm" is not recognized ▼

הסיבה: Node.js לא נוסף ל-PATH של המערכת.

פתרון ל-Windows:

  1. סגרו את הטרמינל / VS Code לגמרי
  2. הריצו מחדש את ההתקנה של Node.js
  3. ודאו שהאפשרות "Add to PATH" מסומנת
  4. הפעילו מחדש את VS Code

פתרון ל-Mac: הפעילו מחדש את הטרמינל. אם לא עוזר — הריצו מחדש את ההתקנה מ-nodejs.org.

שגיאת הרשאות (EACCES / Permission denied) ▼

ב-Windows: פתחו PowerShell כ-Administrator (קליק ימני → "Run as Administrator").

ב-Mac: הוסיפו sudo לפני הפקודה:

sudo npm install -g @anthropic-ai/claude-code
"claude" is not recognized (אחרי התקנה) ▼

פתרון 1: סגרו את כל חלונות הטרמינל / VS Code ופתחו מחדש.

פתרון 2 (Windows): ודאו ש-npm global נמצא ב-PATH:

npm config get prefix
# העתיקו את הנתיב שמופיע והוסיפו אותו ל-PATH של המערכת

פתרון 3: התקינו מחדש:

npm uninstall -g @anthropic-ai/claude-code
npm install -g @anthropic-ai/claude-code
PowerShell חוסם הרצת סקריפטים (Execution Policy) ▼

הבעיה: Windows חוסם הרצת סקריפטים מטעמי אבטחה.

פתרון: פתחו PowerShell כ-Administrator והריצו:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

אשרו עם Y ונסו שוב.

הדפדפן לא נפתח לאימות ▼

כש-Claude Code רץ בפעם הראשונה, הוא צריך לפתוח דפדפן לאימות.

פתרון: אם הדפדפן לא נפתח אוטומטית — חפשו בטרמינל קישור (URL) והעתיקו אותו ידנית לדפדפן.

Mac: "Permission denied" בהגדרת cc alias ▼

אם אתם משתמשים ב-bash ולא ב-zsh:

echo 'alias cc="claude"' >> ~/.bashrc
source ~/.bashrc

לא בטוחים? בדקו:

echo $SHELL
# /bin/zsh = השתמשו ב-.zshrc
# /bin/bash = השתמשו ב-.bashrc

עדיין תקועים? שלחו הודעה בקבוצת הווצאפ ונעזור.
