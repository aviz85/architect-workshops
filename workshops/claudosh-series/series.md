## Core Narrative

**Not "learn Claude Code" → "Build your Personal Operating System"**

The series follows a single story arc: from installing your first agent to having a system that works FOR you 24/7. Each session builds on the previous one - participants MUST attend in order.

### The Story

> You're not learning a tool. You're building an employee.
> Session 1: You hire the employee.
> Session 2: You train the employee.
> Session 3: The employee runs the business while you drink coffee.

### Guiding Principle (Abraham Levy)

> "What already works - keep doing it. Adventure and curiosity - find in additional things. But preserve what exists. The biggest danger is abandoning what works."

Every session reinforces: what you built last time still works and keeps accumulating. Nothing is lost.

## Session 1: Launch 🚀

**Hebrew:** קלודוש - השיגור
**Tagline:** מ-0 לסוכן עובד ב-90 דקות
**Prerequisite:** None
**What they leave with:** Installed agent + first working skill + mind blown

### Core Concept: Breaking the Window

You're stuck in an endless flow of browser tabs, chat windows, emails, notifications. Copy-paste between apps. Context switching. The agent breaks you OUT of that loop. One agent, one conversation, a sequence of tasks - it handles the whole chain while you watch. The "launch" = breaking through the glass ceiling of manual tab-hopping into agent-powered flow.

**Visual metaphor:** Shattering the browser window. Stepping out from behind the screen.

### Philosophy: Fish + Fishing Rod

Give immediate value (fish) AND long-term tools (fishing rod). Nobody leaves empty-handed.

### Agenda (90 min)

| Time | Block | What Happens | Source |
|------|-------|--------------|--------|
| 0:00 | **The News** (15 min) | What is an agent? Doctor metaphor (genius who forgets everything each morning = ChatGPT). Context = everything. The "Killer Prompt" demo - show a complex task that breaks ChatGPT but Claude Code handles. | Beginner workshop + Amaleh |
| 0:15 | **Install Together** (15 min) | Everyone installs Claude Code. Set up `cc` shortcut. Verify it works. Troubleshoot live. | Beginner workshop |
| 0:30 | **First Memory** (15 min) | Write CLAUDE.md together - teach the agent who you are, what you do, how you like things. Show: the agent now "knows" you. | Amaleh + Beginner |
| 0:45 | **First Skill from Library** (15 min) | Install `presentation-architect` skill. Ask the agent to create a presentation about YOUR business. See it execute with YOUR context. The magic: it knows your style because of CLAUDE.md. | Beginner workshop |
| 1:00 | **WOW Live Demo** (15 min) | Aviz shows his real system: sends WhatsApp from agent, creates PDF invoice, generates poster - all from conversation. Show the destination, not just the first step. | Crazy Agent + Before Takeoff |
| 1:15 | **Gift + Bridge** (5 min) | Toolkit gift (email, WhatsApp, images integrations). Preview of Session 2: "Next time - you build a real project, not just install." | Beginner workshop |

### Key Concepts Introduced

- **Project = Folder** - the agent's runway
- **CLAUDE.md = Memory** - the agent's brain
- **Skills = Capabilities** - packaged know-how
- **Context is Everything** - why Claude Code beats chatbots

### Fish (Immediate Value)

- Working Claude Code installation
- One installed skill that does something useful
- CLAUDE.md that knows their business

### Fishing Rod (Long-term Tools)

- Understanding the mental model

## Session 2: Spaceship Mode 🛸

**Hebrew:** קלודוש - מצב חללית
**Tagline:** בונים פרויקט אמיתי מ-א׳ עד ת׳
**Prerequisite:** Session 1 (Launch)
**What they leave with:** 2 working projects + cross-project magic + multi-agent experience

### Core Concept: Multiple Windows, Multiple Projects

Session 1 gave you one agent doing a chain of tasks. Now you multiply: multiple projects open, multiple screens, the agent working across all of them. Like a spaceship command bridge - you're surrounded by screens/windows, each showing a different project, and the agent navigates between them. Cross-project work, parallel tasks, managing complexity through the agent instead of through your own multitasking.

**Visual metaphor:** Working at a multi-screen workstation, holographic windows surrounding you.

### Philosophy: Build, Don't Learn

No slides. No theory. Pure building. Participants create real projects that solve real problems in their lives.

### Agenda (90 min)

| Time | Block | What Happens | Source |
|------|-------|--------------|--------|
| 0:00 | **Status Check** (5 min) | Everyone ready? CLAUDE.md from last time? Quick troubleshoot if needed. | Spaceship workshop |
| 0:05 | **Project 1: Personal CRM** (25 min) | Build customer/contacts management from scratch. Import contacts (Google/Excel). Create CLAUDE.md with business rules. Build skill for generating personalized documents (quotes, contracts). DEMO: "Create a quote for Yossi Cohen" → agent pulls from CRM, generates branded PDF. | Spaceship workshop |
| 0:30 | **Project 2: Content Engine** (25 min) | Build a content creation project for their business. Connect to their brand assets. Build skill for social media posts. Build skill for email newsletters. DEMO: "Write a Facebook post about my new product" → agent writes in their style, with their brand voice. | New - based on content/ folder |
| 0:55 | **Cross-Project Magic** (15 min) | `/add-dir` - connect CRM to Content Engine. DEMO: "Send personalized promotion to all clients who bought X" → agent reads CRM, writes personal message for EACH client, tailored to what they bought. This is the WOW moment. | Spaceship workshop |
| 1:10 | **Semi-Auto Mode** (15 min) | Multi-agent: run 2-3 tasks in parallel. Show the workflow: send task → go make coffee → come back to results. Practice: everyone sends a task and switches to another project while it runs. The mindset shift: manager, not executor. | Spaceship workshop |
| 1:25 | **Bridge to Astronauts** (5 min) | Preview: "You built 2 projects. Imagine 10 projects, all connected, running 24/7, managed from your phone." | New |

### Key Concepts Introduced

- **Semi-Auto (חצי-אוטומאט)** - the sweet spot: manager, not executor
- **Cross-Project** - projects that talk to each other
- **Exponential Efficiency** - each skill becomes foundation for next
- **Automation Ladder** - from executor to manager

### Fish (Immediate Value)

- Working CRM with quote generation
- Content engine that writes in their voice
- Cross-project personalization

### Fishing Rod (Long-term Tools)

- Skill-building muscle
- Cross-project architecture thinking
- Semi-auto workflow habit

## Session 3: Zero Gravity 🌌

**Hebrew:** קלודוש - אפס כבידה
**Tagline:** הסוכנים עובדים, אתה מנהל
**Prerequisite:** Session 2 (Spaceship Mode)
**What they leave with:** Agent team experience + WhatsApp command center + personal OS vision

### Core Concept: Swarm Control from WhatsApp

Session 2 had you at the computer, commanding multiple windows. Now you leave the computer entirely. You control a SWARM of agents from your phone - via WhatsApp. Voice message in, results back. You're floating in zero gravity - no desk, no keyboard, no screen. Just your phone and a network of agents executing. This is the riskiest leap: trusting agents to run without you watching every step.

**Visual metaphor:** Floating above it all, phone in hand, agent swarm orbiting like satellites.

### Philosophy: From Operator to Strategist

This session is about the paradigm shift. You stop doing tasks. Agents do tasks. You make decisions.

### Agenda (90 min)

| Time | Block | What Happens | Source |
|------|-------|--------------|--------|
| 0:00 | **The Ladder** (10 min) | Where are you today? Executor → Manager → Strategist → Approver. Most people are stuck at "executor with a better tool." Today we jump to strategist. Real examples: Obie Fernandez's CTO OS, Teresa Torres's research system. | Zero Friction + Research |
| 0:10 | **Agent Teams** (20 min) | Live demo: spawn 3 agents working on ONE task. Example: "Prepare everything for a client meeting with Yossi Cohen." Agent 1: Pull history from CRM, summarize relationship. Agent 2: Research Yossi's company - latest news, competitors. Agent 3: Draft meeting agenda + follow-up email template. All work simultaneously. Results merge into one briefing document. | Claude Code Teams feature |
| 0:30 | **The Orchestra** (20 min) | Peleg Orchestra concept: WhatsApp as command center. LIVE DEMO: Aviz sends voice message from phone: "Prepare a quote for David Levi, the one we discussed yesterday." Agent spawns → reads CRM → generates PDF → sends back to WhatsApp. Show: reply to continue conversation with same agent. Show: voice message workflow (speak → transcribe → execute). This is "zero friction" in action. | Peleg Orchestra |
| 0:50 | **OpenClaw & Always-On** (15 min) | The agent that lives in your apps. Demo: morning briefing (weather, calendar, priorities). Demo: "Track my expenses this month" → agent scans, categorizes, reports. Demo: scheduled tasks - the agent works while you sleep. The concept: from "I use an AI tool" to "AI runs my operations." | OpenClaw research |
| 1:05 | **Build Your OS** (15 min) | Interactive exercise: each participant maps their "Personal OS." What projects do you need? What skills should each have? How do they connect? What runs on autopilot? Draw the architecture of YOUR system. Aviz reviews 2-3 live. | Zero Friction + Agentic Apps |
| 1:20 | **What's Next** (10 min) | The compound effect - why starting now matters (1% daily = 37x in a year). Community: WhatsApp group for alumni. Mentoring: top graduates help beginners (gym model from Yosef Ratig's feedback). Build in public: share your OS, inspire others. | Course content + Feedback |

### Key Concepts Introduced

- **Agent Teams** - multiple agents collaborating
- **Orchestra** - WhatsApp/voice as command center
- **OpenClaw** - always-on agent in your messaging apps
- **Personal OS** - the complete vision
- **Compound Effect** - 1% daily = 37x yearly

### Fish (Immediate Value)

- Experience with agent teams on real task
- WhatsApp command center demo (can replicate)

### Fishing Rod (Long-term Tools)

- Strategist mindset (not executor)
- System thinking (not tool thinking)
