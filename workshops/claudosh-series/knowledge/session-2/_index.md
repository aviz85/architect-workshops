# Session 2: ערימות של סקילים (Stacks of Skills)

> Source: Deep Interview, 2026-02-15

## Title & Tagline
- **Hebrew:** ערימות של סקילים
- **English:** Stacks of Skills

## Philosophy
- Heavy on practice, light on theory
- Participants arrive with a working project from session 1
- Compounding effect: show how the agent got smarter over the week
- Multi-project, multi-window, semi-auto mode

## Key Decisions
- **Main build:** CRM → Deep Interview → WhatsApp — all three combined into one flow
- **Deep interview skill:** Participants INSTALL from library and USE on themselves (not build it)
- **Spaceship mode:** Live practice - everyone opens 2 projects, sends tasks to both
- **WhatsApp:** Everyone sets up their own Green API connection live

## Key Concepts Introduced
1. Compounding / "interest on interest" with agent work
2. --dangerously-skip-permissions mode (releasing the leash)
3. Multiple projects working together
4. Semi-auto mode (send task → do something else → come back)
5. Subscription optimization (100-200$/month value)

## Narrative Arc
"Last week you built one skill. This week you discover that skills STACK. And when projects talk to each other - magic happens."

## Risks
- WhatsApp setup can be time-consuming with troubleshooting
- Participants may not have completed homework from session 1
- Multiple windows can be overwhelming for beginners
