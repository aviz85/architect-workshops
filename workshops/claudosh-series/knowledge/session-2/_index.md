# Session 2: ערימות של סקילים (Stacks of Skills)

> Source: Deep Interview 2026-02-15, Updated 2026-02-22

## Title & Tagline
- **Hebrew:** ערימות של סקילים
- **English:** Stacks of Skills
- **Tagline:** סקיל אחד = יכולת. ערימה = כוח מצטבר.

## Philosophy
- Heavy on practice, light on theory
- Skills emerge from work, not from planning
- Compounding effect: show how skills stack and multiply
- Participants create real skills for their own projects

## Key Decisions
- **Focus:** Skills anatomy, creation, and stacking (NOT CRM/WhatsApp/Deep Interview)
- **Main exercise:** Create a skill from real work (not from a template)
- **Demo:** Aviz shows real skill stacks from his system
- **No new integrations this session** — focus on the skill concept itself
- WhatsApp/CRM/Deep Interview moved to later (organic integration as skills grow)

## Key Concepts Introduced
1. Skill anatomy (description, instructions, triggers)
2. Global vs project skills (`~/.claude/skills/` vs `.claude/skills/`)
3. Skills emerge from work (capture pattern)
4. Orchestrator skills (skill that calls skills)
5. Compounding / "interest on interest" with skill stacks
6. The factory analogy (workers + manager)

## Narrative Arc
"Last week you met the agent and built your first skill. This week you discover that skills STACK. One skill = one capability. A stack of skills = real power. And the magic? Each new skill multiplies everything you already have."

## Session 1 Recap (for opening)
- The agent lives on your computer
- CLAUDE.md = the agent's memory
- claude-code-guide = the whisperer
- Project = folder + knowledge + skills
- Homework: build a project with first skill

## Risks
- Participants who didn't complete session 1 homework
- Skill creation can be confusing for absolute beginners
- Need ready-made prompts as safety net
