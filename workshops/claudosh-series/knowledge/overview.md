# Series Overview

> Source: Deep Interview, 2026-02-15

## Format
- 4 sessions, 2 hours each
- Hebrew, Zoom
- Target: Early Adopters - no coding background required, but tech-curious and willing to learn

## Core Narrative: The Leash
Progressive autonomy - start with short leash, release gradually through understanding:

```
Session 1: Chat + single action (short leash)
Session 2: Semi-auto + multiple projects (longer leash)
Session 3: Agentic apps + scheduling (off-leash supervised)
Session 4: Swarms + ecosystem (full autonomy)
```

The agent becomes YOUR extended hand, not a foreign tool. Autonomy without understanding is worthless.

## Key Mental Model: The Triangle
```
ידע (Knowledge) → תהליך (Process) → סקיל (Skill) → repeat
```
Each iteration deepens the agent's capability. Compounding effect.
