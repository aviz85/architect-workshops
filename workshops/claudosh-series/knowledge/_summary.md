## The 4 Sessions

### Session 1: הסוכן הכללי כבר כאן 🚀
**The General Agent is Here**
- What makes agents different (duration, scope, personalization)
- Context is king
- "Short leash" philosophy
- Terminal + folder as workspace
- Skills concept
- Exercise: first project (Knowledge → Process → Skill)
- 40/60 theory/practice split

### Session 2: ערימות של סקילים 🛸
**Stacks of Skills**
- Compounding effect
- Release the leash (--dangerously-skip-permissions)
- Build CRM from data
- WhatsApp setup (Green API, everyone sets up their own)
- Deep interview skill (install and use from library)
- Spaceship mode (2 projects, multi-window)
- WOW: personalized client messages
- Heavy practice session (90 min practice / 20 min theory)

### Session 3: אפליקציות סוכניות 🛰️
**Agentic Applications**
- The paradigm shift: agent IS the engine
- 5 building blocks (CLAUDE.md, Skills, Commands, Agents, Data Files)
- Build WhatsApp auto-responder from scratch
- **Hooks & Tool Control (25 min)** - write hooks, configure allow/ask/deny rules
- Agent SDK basics (light hands-on)
- Cron/scheduled tasks
- The agent works while you sleep

### Session 4: נחילי סוכנים 🌌
**Agent Swarms**
- Agent swarms demo (3 agents, 1 task)
- **Prompt Injection & Defense (25 min)** - attack vectors, live demos, security pyramid
- WhatsApp command center (Aviz demo, participants design)
- Design Your Personal OS (exercise, now includes security boundaries)
- Participant showcase
- Vision: compound effect, 1% = 37x

## The Leash Journey (Core Narrative)
```
Session 1: רצועה קצרה → Chat + single action
Session 2: רצועה ארוכה → Semi-auto + multi-project
Session 3: ללא רצועה, עם פיקוח → Agentic apps + scheduling
Session 4: חופש מלא → Swarms + phone control + ecosystem
```

## Security Thread (Woven Throughout)
```
Session 1: Basic safety - permission prompts, don't enter unknown folders
Session 2: Permissions deep dive - skip-permissions, modes, trade-offs
Session 3: Hooks & tool control (25 min) - write hooks, allow/ask/deny rules
Session 4: Prompt injection & defense (25 min) - attack vectors, security pyramid
```

## Key Design Decisions
- **Practice-heavy:** Every session 60%+ hands-on
- **Pre-session install:** Send guide before session 1, verify at start
- **Homework:** Strongly recommended, not enforced
- **Materials:** Full package (recordings, guides, library, templates, community)
- **Multiple metaphors:** Leash + compounding + space + architecture layers
- **Security grows with autonomy:** Each session adds security proportional to freedom
- **WhatsApp:** Participants set up their own connection in session 2
- **Session 3 app:** New standalone WhatsApp auto-responder
- **Session 4:** More demo/design than build - inspirational close

## The Triangle Model (Repeated Every Session)
```
ידע (Knowledge) → תהליך (Process) → סקיל (Skill) → חזרה
```
