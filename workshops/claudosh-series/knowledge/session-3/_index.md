# Session 3: אפליקציות סוכניות (Agentic Applications)

> Source: Deep Interview, 2026-02-15

## Title & Tagline
- **Hebrew:** אפליקציות סוכניות
- **English:** Agentic Applications

## Philosophy
- The paradigm shift: agent IS the engine, documents replace algorithms
- Prove that agentic apps = functionally equivalent to traditional apps
- "You don't need to be a developer to build an application"

## Key Decisions
- **Main build:** New standalone agentic app (NOT building on session 2 CRM)
- **Agent SDK:** Light hands-on - everyone runs a simple script that spawns an agent
- **Automation:** Cron/scheduled tasks (agent runs at specific times)
- No event-triggered automation yet (that's session 4 territory)

## Key Concepts Introduced
1. Agentic app paradigm (5 building blocks: CLAUDE.md, Skills, Commands, Agents, Data Files)
2. Documents replace algorithms (Markdown as database)
3. Agent SDK basics (spawning, monitoring)
4. Scheduled tasks / cron
5. WhatsApp + Email as agentic app interfaces

## Narrative Arc
"You've been building skills and projects. Now discover: what you built IS an application. A new kind of application where the agent is the engine."

## The 5 Building Blocks (from agentic-apps concept)
1. **CLAUDE.md** = Constitution/config
2. **Skills** = Reusable capabilities (like npm packages in natural language)
3. **Commands** = User-triggered actions (like API endpoints)
4. **Agents** = Background processes
5. **Data Files** = Markdown as database
