# Homework & Cross-Session Continuity

> Source: Deep Interview, 2026-02-15

## Homework Philosophy
- **Strongly recommended** but not strictly enforced
- Each session is enriched by homework but followable without it
- Participants who don't do homework will still learn concepts but miss hands-on depth

## Homework Per Session

### After Session 1 → Before Session 2
- Complete the first project (folder + knowledge + skill)
- Use the agent for 3 real tasks during the week
- Add at least 3 things to CLAUDE.md
- Enrich the project's knowledge base

### After Session 2 → Before Session 3
- Enrich CRM with real client data
- Send at least 3 real WhatsApp messages via agent
- Run deep-interview to expand business knowledge
- Experiment with multi-project workflow

### After Session 3 → Before Session 4
- Keep WhatsApp auto-responder running for a week
- Monitor and refine responses
- Add more skills to the agentic app
- Document what works and what doesn't

### After Session 4 (Ongoing)
- Implement the Personal OS design
- Join alumni community
- Keep building, keep compounding

## The Accumulation Principle
Nothing is lost between sessions. Each builds on previous:
```
Week 1: Install + CLAUDE.md + First Skill + First Project
   ↓ (still works, compounding)
Week 2: CRM + WhatsApp + Deep Interview + Multi-Project
   ↓ (still works, now connected)
Week 3: Agentic App + Agent SDK + Scheduling
   ↓ (still works, now automated)
Week 4: Swarms + Command Center + Personal OS Design
   ↓ (everything works, now autonomous)
```

## Participant Materials
- **Full package + community:**
  - Session recordings (shared after each meeting)
  - Written step-by-step guides per session
  - Skill library access
  - Templates and starter files
  - WhatsApp group (cohort)
  - Alumni community (ongoing)
  - Monthly follow-up session
