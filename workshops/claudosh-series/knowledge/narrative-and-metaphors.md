# Narrative & Metaphors

> Source: Deep Interview, 2026-02-15

## Multiple Narrative Layers

The series uses several metaphors simultaneously, each highlighting a different dimension:

### 1. The Leash (רצועה) - Autonomy Dimension
```
Session 1: רצועה קצרה - Short leash, close to you
Session 2: רצועה ארוכה - Longer leash, semi-auto
Session 3: ללא רצועה עם פיקוח - Off-leash, supervised
Session 4: חופש מלא - Full freedom, you set boundaries
```
Metaphor: dog you're training. Trust grows with understanding.

### 2. Stacking / Compounding - Value Dimension
```
Session 1: Foundation (1 project, 1 skill)
Session 2: Multiplication (multiple projects, skill stacks)
Session 3: Application (full agentic app)
Session 4: Ecosystem (everything connected)
```
Metaphor: compound interest (ריבית דריבית). 1% daily = 37x yearly.

### 3. Space Journey - Experience Dimension
```
Session 1: Launch 🚀 (breaking through the atmosphere)
Session 2: Orbit 🛸 (seeing the full picture from above)
Session 3: Space Station 🛰️ (building infrastructure in space)
Session 4: Zero Gravity 🌌 (floating freely, everything works)
```
Metaphor: space exploration. Each session takes you further from earth.

### 4. Architecture Layers - Structure Dimension
```
Session 1: Foundation (knowledge + first skill)
Session 2: Walls (multiple projects, cross-project)
Session 3: Roof (applications, automation)
Session 4: Ecosystem (the whole neighborhood)
```
Metaphor: building a house → building a city.

## The Core Sentence
"You started as operators. You're leaving as architects."

## How to Use the Metaphors
- **Leash:** When discussing autonomy and trust
- **Compounding:** When showing how value accumulates
- **Space:** For session names and visual branding
- **Architecture:** When explaining structure and building blocks
