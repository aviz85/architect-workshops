## Block Details

### Verify Installation (10 min)
- Everyone opens terminal, runs `claude`
- Quick troubleshoot for anyone stuck
- Set up `cc` shortcut
- Show subscription options (20$/month minimum, 100-200$ recommended)

### The General Agent (15 min)
- What makes agent "general" vs chatbot: duration, scope, personalization
- The architecture: brain (model) + tools around it
- Three axes that set agents apart from everything they've seen

### Context Demo (10 min)
- Show /context command live
- Explain context window - the critical limited space
- "If we could describe the exact situation to the model, we'd get AGI-level output"

### Short Leash Philosophy (10 min)
- Mistake #1: building agent before having a goal
- Don't install OpenClaw or ready-made skills
- Start from conversation → single action → gradual autonomy
- Dog metaphor: short leash → longer leash → trust

### Folder = Workspace (15 min)
- Unlike SaaS, agent lives in a folder
- Metaphor: employee gets a folder on their desk
- LIVE: Claude organizes Downloads folder
- LIVE: Add instructions file, Claude follows it
- Security note: don't enter unknown folders

### What is a Skill (15 min)
- Prompt loaded into context only when needed
- Upgrade from Custom GPTs: toolbox of small precise skills
- Example: journal project (entry skill, weekly summary skill, story skill)
- Show Aviz's skill library
- Skills with integrations have setup instructions built in

### WOW Demo (10 min)
- Aviz shows real system running
- WhatsApp, PDF invoice, poster generation - all from conversation
- Show the destination, inspire for the journey

### Exercise: First Project (25 min)
- Choose relevant project (LinkedIn mgmt, shopping list, trip planning, CRM)
- Create folder + add knowledge as text files (explain why .md not .docx)
- Start process with agent, refine until good result
- Ask agent to turn the process into a skill
- Tip: tell agent to consult "claude code guide"

### Wrap-up + Homework (10 min)
- The Triangle: Knowledge → Process → Skill (and repeat)
- CLAUDE.md in user folder = permanent agent rules
- Homework: complete the project, use agent for 3 real tasks this week
- Richer knowledge + more use = more value (compounding preview)
