## Overview

הוובינר מציג את Codex לא כעוד כלי צ'אט לקוד, אלא כסביבת עבודה סוכנית שמחברת מודל שפה עם ראייה, פעולה, יצירת תמונה, קוד, דפדפן, בדיקות, Git וכלים חיצוניים.

הציר המרכזי: מודל שפה לבד הוא מוח בלי גוף. Codex נותן לו מוח, עיניים, ידיים ורגליים.

## Target Audience

- מפתחים שכבר ניסו Claude Code ורוצים להבין מה Codex מוסיף.

## Core Message

Codex מתעלה על Claude Code לא רק בגלל מודל כזה או אחר, אלא בגלל רוחב סביבת העבודה:

- מוח: GPT-5.5 ו-reasoning עמוק.
- עיניים: הבנת תמונה, screenshot, browser ותוצר ויזואלי.
- ידיים: עריכת קבצים, קוד, תמונות, בדיקות ו-Git.
- רגליים: פעולה מרחוק מול GitHub, שרתים, deploys, automations ושירותים חיצוניים.

## Agenda

1. **פתיחה: מוח בלי גוף** - 5 minutes
   - למה צ'אט או IDE assistant לבדם כבר לא מספיקים.
   - מה ההבדל בין תשובה לבין סגירת מעגל.

2. **Context: מ-Claude Code ל-Codex** - 10 minutes
   - מה Claude Code לימד אותנו.
   - למה Codex מרחיב את השדה.

3. **Demo 1: Codex Spark** - 10 minutes
   - מודל מהיר למשימות קצרות.
   - תיקון קטן, scaffold, או test fix.

4. **Demo 2: Native Image** - 10 minutes
   - יצירת אווטאר/ויז'ואל בתוך ה-workbench.
   - שימוש בנכס בתוך חומרי הוובינר.

5. **Demo 3: GPT-5.5 Graphic To Site** - 13 minutes
   - לפרק גרפיקה או screenshot.
   - לבנות ממנה אתר/קומפוננטה באיבחת פרומפט.
   - להסביר למה תמונה הופכת ל-spec.

6. **Demo 4: Closed Loop** - 12 minutes
   - לערוך, להריץ, לראות, לתקן.
   - להראות verification ולא רק generation.

7. **Demo 5: Far-Reaching Legs** - 10 minutes
   - GitHub, שרתים, deploy, automations.
   - Codex כ-operator בעולם האמיתי.

8. **סיכום וקריאה לפעולה** - 5 minutes
   - לבחור workflow אחד.
   - להפוך אותו ללולאה: קלט, פעולה, בדיקה, תיקון, סיכום.
