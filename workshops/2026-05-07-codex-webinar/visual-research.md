# Visual Research: Aviz Workshop Avatar Language

## What The Existing Workshop Visuals Do Well

The current Codex avatar is technically polished but emotionally flat. It looks like a premium generic AI illustration. The successful workshop visuals in this repo do something else: they sell an event.

## Patterns Observed

### 1. Character First, UI Second

Strong assets:
- `workshops/2026-01-01-claude-code-amaleh/assets/avatar.jpg`
- `workshops/2026-01-13-claudosh-beginner/assets/avatar.jpg`
- `workshops/2026-01-20-claudosh-spaceship/assets/avatar.jpg`

Pattern:
- The character has a memorable face and silhouette.
- The costume is simple and iconic: suit, green tie, spaceship suit, baby boss.
- The scene can change, but the character remains recognizable.

Codex mistake:
- The character was too realistic, too generic, and too passive.
- Too much "handsome tech architect", not enough workshop mascot.

### 2. Poster Energy Beats Premium Tastefulness

Strong assets:
- `workshops/2026-01-20-claudosh-spaceship/assets/poster_surf.jpg`
- `workshops/2026-02-05-zero-friction/assets/poster_wow2_impact.jpg`
- `workshops/2026-02-18-agents-madness/assets/poster-v4-breaking-through.jpg`
- `workshops/claudosh-series/assets/poster-v5-2-skills.jpg`

Pattern:
- Big facial expression.
- Action pose.
- Impossible scene.
- Green electric energy.
- Breaking glass, lightning, portals, smoke, speed.
- The viewer understands in 0.5 seconds: "something is happening".

Codex mistake:
- Calm desk scene.
- No danger, no joke, no speed, no punch.
- The metaphor was intellectual instead of visceral.

### 3. Aviz Visual Language Is Controlled Excess

Pattern:
- Exaggerated, but still legible.
- Childlike/fantasy edge, but not childish.
- Cinematic lighting.
- Strong central figure.
- Tech screens and code exist as props, not the main subject.

Codex direction:
- A Codex character should feel like the operator of a machine, not a consultant explaining a machine.

## Revised Avatar Thesis

The new avatar should be:

**Codex Beast Mode / The Four-Limbed Agent**

Not "an architect at a desk".

The character is an Aviz-style mascot in a dark suit/green tie or black tactical suit with a mischievous face, caught mid-action while controlling four superpowers:

- Brain: glowing reasoning reactor above the head.
- Eyes: huge scanner/lens beams seeing screenshots and UI panels.
- Hands: multiple glowing action hands editing code, drawing images, clicking buttons.
- Legs: rocket/portal legs jumping between laptop, GitHub, server and browser worlds.

The image should feel like:
"This thing does not answer you. It breaks through the screen and starts working."

## Avoid List For V2

- No calm desk.
- No realistic male model.
- No tasteful startup editorial look.
- No tiny symbolic lines that require explanation.
- No beige studio.
- No generic UI collage.
- No "AI assistant in hoodie".

## Must Have For V2

- Big mascot face.
- Green energy as the main brand signal.
- One impossible action pose.
- Strong silhouette readable at thumbnail size.
- A little chaos.
- A little humor.
- One clear metaphor: Codex got a body.
