# Image Prompt: Codex Beast Mode Avatar

Use case: ads-marketing
Asset type: webinar hero avatar and brand key visual
Primary request: Create a wild, charismatic Aviz-style workshop avatar for a Hebrew webinar about Codex as an agentic workbench that gives a language model a brain, eyes, hands, and legs.

Scene/backdrop:
A cinematic high-energy tech stage, like a spaceship cockpit colliding with a coding command center. Green lightning, glass shards, floating browser windows, code panels, image canvas, Git graph, server boxes, and deploy portals explode outward from the central character. The scene should feel like a live event poster, not a calm startup illustration.

Subject:
A central "Codex Beast Mode" mascot character: stylized 3D / animated film quality, expressive face, mischievous confident grin, big eyes, strong eyebrows, Aviz workshop energy. Outfit: black suit or black tactical work suit with a vivid green tie/accent, heroic but a little absurd. The character is mid-action, breaking through a screen or leaping out of a terminal portal, not standing politely.

Symbolic system:
- Brain: a glowing reasoning reactor above/behind the head, like a crown of electric thought.
- Eyes: scanner beams or huge lens effects seeing screenshots and browser panels.
- Hands: exaggerated glowing action hands controlling code edits, image generation, file operations, and tests.
- Legs: rocket/portal legs or green motion trails jumping between laptop, GitHub, remote servers, browser, and deployment worlds.

Style:
Aviz workshop poster style: controlled excess, cinematic 3D mascot, green electric energy, action pose, broken glass, smoke, speed, dramatic perspective, clear central silhouette, humorous but powerful. It should make people want to click because something dramatic is happening.

Palette:
Black, electric green, white highlights, a little cyan for vision, small orange sparks for action. Green should dominate like the existing Claude/Codex workshop assets.

Text:
No text inside the image.

Avoid:
No logos, no watermarks, no fake readable UI text, no generic realistic tech guy, no calm desk scene, no beige studio, no tasteful LinkedIn illustration, no passive pose.

Thumbnail test:
At small size, the viewer should immediately see: expressive mascot, green energy, action, "AI got a body".
