A clean high-end digital studio, like an architect's desk fused with a coding workbench. The background includes subtle layers of browser windows, terminal panes, image canvas, Git graph lines, and deployment paths. Keep the composition readable and iconic, not cluttered.

A central "Architect Agent" character, human-like but slightly stylized, confident and intelligent, wearing a black hoodie with architect/workshop details. The character is not a generic robot. One hand holds a glowing stylus, one hand is near a code/workbench interface.

Symbolic system:

- Eyes: a cyan lens/eye motif suggesting vision, screenshots, browser inspection.

- Legs: green path lines extending outward toward servers, GitHub, deploys, automations.

Style:
Premium editorial tech illustration, cinematic but bright enough for a webinar hero. Sharp composition, strong silhouette, crisp details, tasteful lighting, practical startup/product aesthetic. Avoid generic AI blue-purple cyberpunk.

Palette:
Ink black, warm paper white, signal cyan, craft orange, electric green, warm gray.

Text:
No text inside the image.

Avoid:
No logos, no watermarks, no fake UI text, no extra characters, no childish mascot, no dark sci-fi spaceship feeling.
