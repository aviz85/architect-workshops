# תוכנית וובינר: Codex Beyond Claude Code

## שם עבודה

Codex: מוח, עיניים, ידיים ורגליים

## הבטחה למשתתפים

בסוף הוובינר המשתתף יבין למה Codex הוא לא רק "AI שכותב קוד", אלא סביבת עבודה סוכנית שמחברת הבנה, ראייה, פעולה ואימות בתוך אותו רצף עבודה.

## קהל יעד

- מפתחים שכבר ניסו Claude Code או ChatGPT לקוד.
- יזמים ובוני מוצרים שרוצים לזוז מהר יותר.
- אנשי AI שרוצים להבין את המעבר מצ'אט אל agentic workflow.
- אנשים סקפטיים שצריכים לראות דמוים אמיתיים, לא הבטחות.

## Narrative Arc

1. הבעיה: מודל שפה לבד הוא מוח בלי גוף.
2. הטענה: Codex הוא לא AGI רשמי, אבל הוא המוצר שהכי מרגיש כמו AGI מעשי כרגע.
3. ההיפוך: סביבת עבודה סוכנית נותנת למוח חושים, ידיים ורגליים.
4. ההדגמה: חמש יכולות שבהן Codex מרגיש כמו קפיצה איכותית.
5. המשמעות: זה משנה את מי שיכול לבנות, כמה מהר, ובאיזה עומק.
6. הקריאה לפעולה: לבנות workflow ראשון, לא רק "לנסות פרומפט".

## מבנה זמן מוצע - 75 דקות

### 00:00-05:00 פתיחה

מסר: "היום לא נדבר על עוד כלי קוד. נראה מה קורה כשמודל שפה מקבל גוף."

פעולה:
- להראות את המטאפורה: מוח, עיניים, ידיים, רגליים.
- למסגר בזהירות: "לא AGI רשמי, כן המוצר הכי AGI-like בעבודה אמיתית."
- להבטיח חמש הדגמות קצרות.

### 05:00-15:00 Context: למה Claude Code היה קפיצה ולמה Codex הולך צעד נוסף

מסר:
- Claude Code לימד אותנו לעבוד עם AI בתוך קודבייס.
- Codex מרחיב את השדה: קוד, תמונה, דפדפן, קבצים, agents, automations, בדיקות, Git.

ניסוח מפתח:
"ההבדל הוא לא עוד 12% בבנצ'מארק. ההבדל הוא שהכלי רואה יותר מהעולם ופועל ביותר מקומות."

טענת AGI-like:
"אם AGI זה לא רק לדעת לענות אלא להתחיל לעבוד בעולם - Codex הוא המלך החדש כי הוא מחבר מוח, ראייה, פעולה, כלים, זיכרון ואימות בתוך סביבת עבודה אחת."

### 15:00-25:00 Demo 1: Codex Spark

מסר:

### 25:00-35:00 Demo 2: Native Image

מטרה: להראות שהוורקבנצ' כולל יצירת ויז'ואלים, לא רק טקסט וקוד.

דמו אפשרי:

- ליצור hero visual או social post.
- להשתמש בתוצאה כחומר גלם לעמוד נחיתה.

מסר:
"כשאפשר ליצור נכסי מותג בתוך אותו רצף עבודה, הקיר בין רעיון לביצוע נהיה דק."

### 35:00-48:00 Demo 3: Graphic To Site

מטרה: להראות GPT-5.5 מפרק גרפיקה ובונה ממנה אתר.

דמו אפשרי:
- להראות תמונה/פוסטר/סקיצה.
- לבקש: "בנה מזה landing page עובד".
- להריץ, לצלם, לתקן layout.

למה זה משמעותי:
- מעביר אותנו מ-spec מילולי ל-spec ויזואלי.
- מאפשר למעצבים, יזמים ואנשים לא טכניים להכתיב כיוון בלי לדעת CSS.
- מקצר את המרחק בין moodboard לבין מוצר עובד.

### 48:00-60:00 Demo 4: Closed Loop

מטרה: להראות את סגירת המעגל: לא רק הצעה, אלא פעולה ואימות.

דמו אפשרי:

- להריץ dev server.
- לפתוח דפדפן.
- לצלם/לבדוק.
- לתקן בעיית overlap או responsive.
- לסכם מה השתנה.

מסר:
"הקסם הוא לא שהמודל צדק בפעם הראשונה. הקסם הוא שהוא יודע להסתכל שוב ולתקן."

### 60:00-70:00 Demo 5: Far-Reaching Legs

מטרה: להראות פעולה מעבר למחשב המקומי.

דמו אפשרי:
- GitHub issue/PR.
- deploy.
- בדיקת שרת.
- automation/follow-up.

מסר:
"רגליים זה היכולת לצאת מהקובץ המקומי אל העולם האמיתי: שרתים, דפדפן, ריפו, שירותים, לקוחות."

### 70:00-75:00 סיכום וקריאה לפעולה

מסר סיום:
"Codex הוא לא כלי שעונה. הוא סביבת עבודה שמתחילה לסגור מעגלים. מי שילמד לתת לו משימות, לא רק שאלות, יקבל יתרון."

קריאה לפעולה:
- בחר workflow אחד שחוזר אצלך.
- הפוך אותו ל-agentic loop: קלט, פעולה, בדיקה, תיקון, סיכום.
- תתחיל קטן, אבל תסגור מעגל.
