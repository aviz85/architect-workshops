## פירוט: הסקיל הראשון שלי (7 דק')

**זה הלב של הקורס!** כאן הם עושים משהו אמיתי.

### מה בונים
סקיל פשוט: "תזכורת יומית" או "תבנית מייל"

### הצעדים
1. יוצרים תיקייה: `~/.claude/skills/my-first-skill/`
2. כותבים `SKILL.md`:
   ```markdown
   ---
   name: my-first-skill
   description: "תזכורת יומית פשוטה"
   ---

   # My First Skill

   כשהמשתמש מבקש תזכורת, תעזור לו לכתוב אותה.

   ## פורמט
   - כותרת קצרה
   - תאריך ושעה
   - תוכן התזכורת
   ```
3. בודקים שעובד: "תזכיר לי משהו"
4. **חוגגים!** 🎉

## קונספטים מרכזיים לשלב

### 1% = 37x
```
1.01^365 = 37.78
```
אם משתפרים 1% כל יום, בסוף השנה אתה פי 37 יותר טוב.

### חצי-אוטומאט
לא פינג-פונג ידני, לא אוטונומיה מלאה.
שולח משימה → עושה משהו אחר → חוזר לתוצאה.
מנהל, לא מבצע.

### התייעלות אקספוננציאלית
כל סקיל הופך לבסיס לסקיל הבא.
שכבות נערמות. הערך מכפיל את עצמו.
