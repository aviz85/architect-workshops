## Visual Assets

Primary logo:

```text

```

Use the logo in the document header. It should be small and official, around 60-80 px in browser-rendered HTML.

Avoid avatars in contracts by default:

- `avatar-classic.jpg` and `avatar-boss.png` are good for workshop posters and aspirational marketing.
- Contracts should feel official and trustworthy, so prefer the logo only.
- Use a real photo or avatar only if Aviz explicitly asks for a more personal/promotional document.

## Colors

- Dark green: `#16A34A`
- Main ink: `#111827`

- Muted text: `#4b5563`

- Soft green background: `#f0fdf4`

Use green as an accent: header line, notice border, section underline, footer brand. Do not make the whole document green.

## Typography and Layout

- Use clean sans-serif fonts: `Arial`, `Noto Sans Hebrew`, `Noto Sans`, `Assistant` if available.
- A4 page, margins around `20mm 18mm`.
- Document direction is RTL.
- Emails, URLs, English technical identifiers, and file paths stay LTR.
- Keep headings compact. This is a contract, not a landing page.

## Header Pattern

Recommended header:

- Right side: logo, `אביץ הארכיטקט`, `AVIZ - The Architect`, legal/business line.
- Left side: email, phone, linktree, document date in LTR.
- Bottom: green rule using `#22C55E`.

## Contract Tone

Write in Hebrew that is professional, clear, and direct:

- Warm but not salesy.
- Practical clauses rather than legal theatrics.
- Clear payment and cancellation terms.
- Explicit boundaries around recordings, distribution, and reuse of materials.
