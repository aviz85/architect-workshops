## Sync Notes

`.claude/skills` is still the original source for existing workshop workflows. When a skill changes there, mirror the change here and adapt hard-coded paths from `.claude/skills` to `.codex/skills`.

Prefer `SKILL.md` as the entrypoint filename for Codex.
