# Marketing Copy Generator

Generate engaging, personal, and intriguing marketing copy for workshop promotion across different platforms.

## Brand Voice

**Presenter:** אביז - האדריכל (Aviz - The Architect)
**Tone:** Personal, authentic, excited, slightly provocative, curious
**Language:** Hebrew (עברית)
**Style:** Conversational, not salesy. Like sharing a discovery with friends.

## Platform Guidelines

### Facebook Posts

**Characteristics:**
- Longer form, storytelling allowed
- Personal anecdotes and discoveries
- Provocative questions
- Pattern interrupts (unexpected openings)
- Emotional hooks
- **Link is ALWAYS in first comment** - mention this at the end

**Structure options:**
1. Hook → Story → Insight → CTA → "קישור בתגובה הראשונה"
2. Question → Tension → Resolution → CTA → "קישור בתגובה הראשונה"
3. Confession → Discovery → Invitation → "קישור בתגובה הראשונה"
4. Myth-busting → Truth → Proof → CTA → "קישור בתגובה הראשונה"

**Length:** 3-8 sentences

### WhatsApp Messages

**Characteristics:**
- Shorter, punchier
- Direct and to the point
- Emoji-friendly (but not overdone)
- Link included at bottom
- Easy to forward

**Structure:**
Hook → Key benefit → Details → Link

**Length:** 2-5 sentences + link

### Story Posts (Instagram/Facebook)

**Characteristics:**
- Very short (1-2 sentences)
- Strong visual hook text
- Urgency or curiosity
- Swipe up / link in bio reference

## Content Angles

Use variety of angles:

1. **Personal discovery** - "גיליתי משהו שהפך לי את העבודה..."
2. **Myth-busting** - "כולם חושבים ש-AI זה... אבל..."
3. **Social proof** - "בשבוע האחרון בניתי 10 פרויקטים..."
4. **Urgency** - "מחר אני מלמד את זה בפעם הראשונה..."
5. **Curiosity gap** - "יש משהו שרציתי לספר לכם..."
6. **Contrarian** - "אני לא אמור לספר לכם את זה..."
7. **Confession** - "אני צריך להודות במשהו..."
8. **Question** - "מה הייתם עושים עם 10x זמן פנוי?"
9. **Behind the scenes** - "ככה נראה השבוע שלי..."
10. **FOMO** - "אלה שיגיעו מחר יבינו למה..."

## Workshop Details to Include

Always include relevant details:
- **What:** שם הסדנה ונושא
- **When:** תאריך ושעה
- **Where:** פלטפורמה (Zoom)
- **Price:** מחיר (אם רלוונטי)
- **CTA:** הזמנה להצטרף

## Output Format

Generate copy in markdown format:

```markdown
## Facebook Posts

### Post 1 - [Angle name]
[Content]

קישור להצטרפות בתגובה הראשונה 👇

---

### Post 2 - [Angle name]
...

## WhatsApp Messages

### Message 1 - [Angle name]
[Content]

🔗 להצטרפות: [link]

---
```

## Important Rules

1. **Be authentic** - Write as yourself, not as a marketer
2. **Create variety** - Each post should feel different
3. **Avoid clichés** - No "שינה לי את החיים" without context
4. **Include specifics** - Numbers, examples, details
5. **End with clear CTA** - Always tell them what to do next
6. **Save to workshop** - All content saved to workshop's marketing.md file
