# Skill: Capture Founding Text

Transform raw reflections and insights into structured assets.

## When to Use

User shares a long-form reflection, manifesto, or insight that feels "foundational" - something worth preserving and building upon.

**Triggers:**
- "learn from this"
- "this is important"
- "save this as a concept"
- User shares a substantial personal reflection (500+ words)

## What This Skill Produces

From one founding text, create **three assets**:

### 1. Future Concept (`future-concepts/[topic-name].md`)
A structured workshop/course concept including:
- The Big Idea (core philosophy)
- The paradigm shift
- The gap to bridge (current reality vs desired state)
- Step-by-step methodology
- Packaging options (mini-kit, workshop, course, B2B)
- Marketing angles
- Key quotes (Hebrew original)
- Next steps checklist

### 2. Social Media Post (`content/30-posts.md`)
Add a new numbered post:
- Long-form Facebook version
- Captures essence in shareable format
- Hebrew, personal tone
- Ends with relevant hashtags

### 3. Quotes File (`content/quotes/[topic-name].md`)
Extract 5-10 quotable lines:
- Original Hebrew phrasing
- English translation if useful
- Context tag (philosophy, method, pain-point, promise)

## Process

1. **Read** the founding text carefully
2. **Identify** core philosophy, methodology, gaps, examples
3. **Extract** quotable moments
4. **Generate** all three assets
5. **Commit** each file separately with clear message
6. **Push** to remote

## Output Format

After completion, summarize:
```
Created from founding text "[title]":
- future-concepts/[file].md - [brief description]
- content/30-posts.md - Post #[N] added
- content/quotes/[file].md - [N] quotes extracted
```

## Example Transformation

**Input:** 2000-word reflection on "The Method" - how skills emerge from friction

**Output:**
1. `future-concepts/the-method-friction-to-asset.md` - Full concept with paradigm shift, methodology, packaging options
2. Post #31 in `30-posts.md` - Facebook-ready version
3. `content/quotes/the-method.md` - 7 key quotes about effort, friction, compounding

## Notes

- Preserve Hebrew originals for quotes
- Keep the personal voice in posts
- Concept docs are in English (per CLAUDE.md rules)
- Marketing content stays Hebrew
