# מיתוג: Codex - מוח, עיניים, ידיים ורגליים

## Brand Position

Codex מוצג כ-workbench חי: לא "עוזר קוד", אלא גוף עבודה שלם סביב מודל שפה.

## Tone

- חד, פרקטי, חי.
- פחות "עתידנות נוצצת", יותר "תראה מה זה עושה עכשיו".
- ביטחון בלי הייפ ריק.
- דמואים לפני סיסמאות.

## Visual Idea

דמות מרכזית: The Architect Agent.

דמות חצי-אנושית חצי-כלי עבודה, עומדת מול שולחן עבודה דיגיטלי. מסביבה ארבע יכולות:

- מוח מואר: reasoning, planning, GPT-5.5.
- עיניים/עדשה: vision, screenshots, browser inspection.
- ידיים: code editing, image generation, file operations.
- רגליים/נתיבים: remote servers, GitHub, deploys, automations.

הדמות לא צריכה להיות רובוטית מדי. היא צריכה להרגיש כמו אדריכל-מבצע: יצירתית, חכמה, ומסוגלת לזוז בעולם.

## Name Options

- Codex: מוח עם גוף
- Codex Beyond Claude Code
- Codex Workbench
- מהצ'אט אל הפעולה
- Agentic Coding: לראות, לחשוב, לפעול

השם המומלץ:

**Codex: מוח עם גוף**

הוא קצר, זכיר, ומסביר את ההבדל האמיתי.

## Palette

- Ink Black: `#101014`
- Paper White: `#F7F4EE`
- Signal Cyan: `#00AEEF`
- Craft Orange: `#FF7A1A`
- Electric Green: `#28D17C`
- Warm Gray: `#C9C1B6`

שימוש:
- רקע בהיר וחם או שחור נקי.
- cyan לעיניים/vision.
- orange לידיים/action.
- green לרגליים/remote/live systems.
- לבן/שחור למוח ולשפה הטקסטואלית.

## Typography Direction

- כותרות: sans bold condensed, תחושה טכנית-אדריכלית.
- גוף: sans נקי, קריא, צפוף יחסית.
- שקפים: מעט טקסט, הרבה דמו.

## Key Phrases

- מודל שפה לבד הוא מוח בלי גוף.
- Codex נותן למודל עיניים, ידיים ורגליים.
- לא שואלים אותו. נותנים לו לסגור מעגל.
- מפרומפט לתוצר, מתוצר לבדיקה, מבדיקה לתיקון.
- היכולת הכי חשובה היא לא ליצור. היא לאמת ולתקן.

## Avatar Concept

שם פנימי: Architect Agent

מאפיינים:
- מבט חכם וישיר.
- לבוש בין hoodie שחור לאפוד אדריכל.
- יד אחת מחזיקה stylus או עט אור.
- יד שנייה ליד מסך קוד/ממשק.
- מאחוריו שכבות: wireframe, browser, terminal, image canvas, Git graph.
- סביבו ארבעה אייקונים/איברים מופשטים: מוח, עין, יד, נתיב רגליים.

לא לעשות:
- לא רובוט גנרי.
- לא חללית AI כחולה.
- לא סייברפאנק חשוך מדי.
- לא mascot ילדותי.
