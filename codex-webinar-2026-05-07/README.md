# Codex Webinar - 2026-05-07

וובינר הדגמה על Codex כ-Agentic Workbench: מוח, עיניים, ידיים ורגליים למי שבונה בעידן שבו מודל שפה לבד כבר לא מספיק.

## One-Liner

קודקס הוא לא עוד חלון צ'אט לקוד. הוא סביבת עבודה שבה מודל שפה רואה, מצייר, משנה קבצים, מריץ, בודק, מפעיל כלים וסוגר מעגלים.

## Core Metaphor

- מוח: GPT-5.5 והמודלים החזקים שמפרקים בעיות, גרפיקה, ארכיטקטורה וקוד.
- עיניים: יכולת לראות מסכים, תמונות, דפדפן, תוצאות ובאגים ויזואליים.
- ידיים: עריכת קוד, קבצים, Git, מסמכים, תמונות, בדיקות והרצות.
- רגליים: פעולה מרחוק דרך שרתים, דפדפן, כלים, אוטומציות, GitHub, Vercel ומערכות חיצוניות.

## Five Demos

1. Codex Spark: מודל מהיר וקטלני למשימות קצרות, תיקונים, scaffolding ובדיקות זריזות.
2. Native Image: יצירת ויז'ואלים, אווטארים, assets ומיתוג בלי לצאת מה-workbench.
3. Graphic To Site: GPT-5.5 מפרק גרפיקה או צילום מסך ובונה ממנה אתר/קומפוננטה בפרומפט אחד.
4. Closed Loop Agent: קודקס לא רק מציע, אלא משנה, מריץ, בודק, מצלם, מתקן ומסכם.
5. Far-Reaching Legs: עבודה על שירותים אמיתיים מרחוק: GitHub, שרתים, דפדפן, deploy, automations.
